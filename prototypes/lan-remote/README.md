# Mira 局域网对话交互原型

状态：待用户确认。仅原型，不是产品实现。

打开 `index.html` 可离线操作，无第三方依赖。也可在仓库根目录运行 `python -m http.server 8768 --bind 127.0.0.1` 后访问 http://127.0.0.1:8768/prototypes/lan-remote/index.html 。本地预览服务只绑定回环地址，不是局域网产品服务。

配套 PRD：../../docs/MIRA_LAN_REMOTE_PRD.md

流程：开启连接 → 模拟手机扫码 → 电脑允许 → 选择任务 → 发送或审批。顶部切换手机／平板，下方提供断网、过期、空态、撤权等演示按钮。重置恢复初始数据。

所有地址、设备名、消息、审批与模型选项为虚构演示；无真实二维码、网络配对、模型请求、文件修改或配置写入。模型选择仅保留示意选中状态。配对有效期通过“链接过期”按钮演示；不运行五分钟计时。原型未覆盖真实网卡选择、防火墙、并发双端抢答、第二设备替换和历史分页，这些仍由 PRD 定义。

已检查：JavaScript 语法；Node VM 流程烟测（配对／审批／发送／排队／停止／离线／平板项目范围）；浏览器配对、审批、发送、离线禁用和平板布局。截图为本地浏览器模拟画布，不是实体手机或局域网验收。

0.2 更新：范围改为全部项目空间（排除空间外任务）；可选择模型／思考／当前任务权限；加号只提供手机文件与照片。附件只保留内存元信息，不读取或上传内容。文件卡、变更和执行详情可点击并显示指定电脑端使用 Toast；实际对话渲染一致性尚待产品实现。
# PC 组件移动端预览（2026-10-21）

入口：`pc-preview.html`。构建：`node scripts/build-lan-mobile-preview.mjs`，然后在仓库根目录启动 `python -m http.server 8768 --bind 127.0.0.1`，访问 `http://127.0.0.1:8768/prototypes/lan-remote/pc-preview.html`。

此版直接使用 PC 的 UserMessage、AssistantMessage、MiraPromptEditor、MiraModelMenu、ComposerPermissionOptions、ComposerReasoningOptions 和 app.css。仅新增手机抽屉、平板两栏及触摸尺寸的布局样式。生产入口未接入此演示。

可操作：项目任务切换、各任务独立草稿／附件／选择项、模型搜索切换、思考与权限切换、文件／照片原生选择器、本地演示发送、明暗主题、文件和网页链接拦截 Toast。

限制：这是 UI 评审产物，所有项目、对话与模型均为示例；没有局域网监听、配对、电脑确认、真实任务同步、模型调用、附件上传或权限变更。文件仅保留浏览器 File 对象及文件名，刷新后清除。20 MB／5 个附件为预览限制，正式限制仍须按宿主能力决定。真实权限审批、问答、停止、离线重连需后续接入验证。

验证：React 及预览 TypeScript 检查、独立预览构建通过；浏览器检查 390×844 手机明暗及 1024×768 平板深色，验证菜单、模型搜索、权限／思考切换、草稿跨任务恢复、本地发送及链接拦截。没有真实手机或平板设备联调。
