# Mira 局域网对话交互原型

状态：待用户确认。仅原型，不是产品实现。

打开 `index.html` 可离线操作，无第三方依赖。也可在仓库根目录运行 `python -m http.server 8768 --bind 127.0.0.1` 后访问 http://127.0.0.1:8768/prototypes/lan-remote/index.html 。本地预览服务只绑定回环地址，不是局域网产品服务。

配套 PRD：../../docs/MIRA_LAN_REMOTE_PRD.md

流程：开启连接 → 模拟手机扫码 → 电脑允许 → 选择任务 → 发送或审批。顶部切换手机／平板，下方提供断网、过期、空态、撤权等演示按钮。重置恢复初始数据。

所有地址、设备名、消息、审批与模型选项为虚构演示；无真实二维码、网络配对、模型请求、文件修改或配置写入。模型选择仅保留示意选中状态。配对有效期通过“链接过期”按钮演示；不运行五分钟计时。原型未覆盖真实网卡选择、防火墙、并发双端抢答、第二设备替换和历史分页，这些仍由 PRD 定义。

已检查：JavaScript 语法；Node VM 流程烟测（配对／审批／发送／排队／停止／离线／平板项目范围）；浏览器配对、审批、发送、离线禁用和平板布局。截图为本地浏览器模拟画布，不是实体手机或局域网验收。

0.2 更新：范围改为全部项目空间（排除空间外任务）；可选择模型／思考／当前任务权限；加号只提供手机文件与照片。附件只保留内存元信息，不读取或上传内容。文件卡、变更和执行详情可点击并显示指定电脑端使用 Toast；实际对话渲染一致性尚待产品实现。
