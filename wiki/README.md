- 使用大写字母和下划线：`SCSS_MIGRATION_GUIDE.md`
- 英文命名，便于跨平台兼容
- 见名知意，清晰描述文档内容

适合放置：

- 功能开发指南

## 📌 文档维护

### 添加新文档
1. 确定文档类型（guide / reference / report）
2. 创建文档并放入对应目录
3. 更新本 README 的文档列表
4. 如需要，添加到快速导航

### 更新现有文档
- 文档顶部添加"最后更新"日期
- 重大更新请在文档内说明变更内容
- 保持文档与代码同步

### 文档归档
- 过时的文档移动到 `archive/` 目录
- 在原位置添加跳转说明
- 保留归档文档以供历史查询
