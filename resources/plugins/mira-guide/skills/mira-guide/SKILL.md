# Mira 使用指南

Mira 是围绕本地工作区的桌面助手。侧栏可新建任务、搜索、打开自动化和插件市场。项目绑定本地目录，个人任务使用个人工作区。插件市场的公共页用于发现插件，本地页管理本机插件，添加菜单可添加插件市场或本地插件。输入 @ 引用插件 Skill 或智能体，消息开头输入 / 选择命令。插件 MCP 需要在任务 MCP 选择器中选择；Hook 需要在设置中审阅授权。安装或启用插件后新任务可使用，已有任务保留原能力快照。移除本地插件只移除登记，原文件保留。权限和模型在设置中配置。回答使用问题时，以当前界面、工具返回和本指南为准，不虚构不存在的菜单或宿主能力。
