# duke-sheets WebAssembly

Mira ships the WASM distributed by `@extend-ai/react-xlsx@0.16.0`, which depends on
`@dukelib/sheets-wasm@0.1.21`. Both packages declare MIT licensing.
The sheets-wasm npm tarball omits its LICENSE; this directory preserves the
upstream repository license, retrieved on 2026-10-12 from
https://github.com/guseggert/duke-sheets/blob/main/LICENSE.
No WASM source or binary changes are made by Mira.
