# 2026-07-15 工作日志

## 项目分析

对 core-platform（中台基座）项目进行了全面分析。

### 项目概况
- Vue 3.5 + TS 5.7 + Vite 6.0 + Element Plus 2.14 + Pinia 3.0 + SCSS
- 34 个源文件，~4077 行代码，v1.1.0
- Git 在 dev 分支，5 个提交

### 架构亮点
- 分层清晰：layouts / pages / stores / config / styles / types / router
- SCSS 设计系统：60+ 设计令牌，30+ mixin，Vite additionalData 自动注入
- 主题双变量系统：SCSS 变量（编译时）+ CSS 变量（运行时），Element Plus 变量全覆盖
- View Transition API 圆形扩散主题切换动画，有 prefers-reduced-motion 降级
- 3 种布局模式 + 6 种页面切换动画
- 4 个 Pinia store，layoutStore 用 persistedstate 自动持久化

### 发现的问题
- **P0**: user.ts 内嵌 797KB base64 头像图片（102 行代码中大部分是 base64）
- **P0**: dist/ 被提交到 Git
- **P1**: 硬编码 demo 登录（admin/12345678），无 API 抽象层
- **P1**: refreshTokenExpire() 死代码，定义但未调用
- **P1**: vite.config.ts 端口 9000 vs README 9001 不一致
- **P1**: App.vue 空 onMounted 钩子 + 无用 useRouter import
- **P2**: 缺少 ESLint/Prettier/Stylelint
- **P2**: 无单元测试/E2E 测试
- **P2**: 无 .env 环境变量配置
- **P2**: Dashboard 硬编码 mock 数据
- **P2**: 路由守卫 JSON.parse 无 try-catch

## 产品设计 v2.0 方案

与老大进行了多轮对话，敲定了中台基座 v2.0 重新设计方案：

### 定位
通用中后台脚手架，Mock + 预留接口，更现代精致风格（Linear/Vercel 方向）

### 功能决策
- 保留全部现有模块（认证/系统管理/布局主题动画/Dashboard）
- 新增：多标签页导航、顶栏增强、业务组件库(ProTable/ProForm/DetailLayout)、新页面模块(操作日志/系统设置/部门管理/个人中心/消息中心/组件演示)
- 登录页/注册页：完全不做任何修改，原样保留

### 技术选型
- 图表：ECharts
- 路由：动态路由（现阶段 config mock 数据，后期转 API）
- HTTP：axios
- i18n：预留架构暂不集成

### 实施阶段
1. 基础设施（API层/Mock/清理债务）
2. 布局重构（分层架构/PageContainer/多标签页/顶栏增强/配置面板升级/动态路由）
3. 核心组件（ProTable/ProForm）
4. 业务页面（系统管理 CRUD）
5. 新增页面（个人中心/消息中心/组件演示）
6. 打磨（Dashboard图表/暗色模式）

### Layout 重构方案
- 现有布局太扁平（像原型展示），重构为分层架构：Sidebar → MainWrapper → (Header → TabsBar → PageContainer → Footer)
- 每层独立可配置
- 新增 PageContainer 组件：页头(title+desc+actions) + 内容区(max-width/内边距可配置)
- 新增布局模式：mixed(双栏侧边) / top-menu(顶部水平菜单)
- 侧边栏增强：宽度可配置(200~280)、折叠宽度(48~80)、唯一展开
- AppFooter 重构：3 种样式(simple/split/multi)、版权文本可自定义、年份auto/自定义、备案号、额外链接列表、高度可配置

### 配置面板升级方案
- 现有只有 5 项配置，太少且粗糙
- 升级为 7 大模块 28+ 项配置：整体风格/布局设置/顶栏设置/多标签页/动画效果/底栏设置/其他
- 新增：暗色模式切换、侧边栏宽度滑块、圆角风格、组件大小、内容区max-width、水印等
- 新增底栏设置模块：版权文本、版权年份(auto/自定义)、备案号+链接、额外链接动态列表、底栏样式(simple/split/multi)、底栏高度
- 面板 UI 升级：section 可折叠、实时预览、复制配置JSON

### 详细模块设计（第三轮）
- 多标签页：3种样式(card/chrome/plain)做配置项，右键菜单6项(刷新/关闭当前/关闭其他/关闭左侧/关闭右侧/关闭全部)
- 顶栏全局搜索：Linear/Raycast风格命令面板，模糊匹配+分类筛选+键盘导航+最多8条结果
- 通知铃铛：下拉面板分通知/公告Tab，数据结构含type/title/content/isRead/link，最多5条
- 用户下拉：用户信息区(头像+昵称+角色+状态)+菜单项(个人中心/系统设置/消息通知/主题设置/布局配置)+退出(珊瑚色)
- Dashboard：4统计卡片(含sparkline+环比)+ECharts双折线趋势图+6快捷入口+待办列表
- ProTable：完整props(columns/search/toolbar/actions)+插槽规范+工具栏(刷新/密度/列设置)
- ProForm：schema驱动+16种字段类型+显隐联动+选项联动+禁用联动+分步表单
- 系统管理6页面：用户(ProTable+CRUD弹窗)/角色(权限树抽屉)/菜单(树表+类型动态显隐)/日志(详情抽屉+导出)/设置(3Tab)/部门(左树右表)
- API层：axios封装+请求/响应拦截器+模块化API
- Mock架构：vite-plugin-mock+模块化Mock文件+dev环境拦截+零成本切换真实后端
- 权限系统：三层(路由动态注册+菜单过滤+按钮v-permission)+权限标识规范(模块:资源:操作)+usePermission hook
- 个人中心：左侧Tab(个人资料/安全设置)+头像上传+修改密码(强度提示)+登录记录
- 消息中心：消息卡片列表(非表格)+Tab分类(全部/通知/公告)+通知设置矩阵
