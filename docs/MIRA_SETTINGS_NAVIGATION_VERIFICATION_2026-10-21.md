# 设置菜单分层吸附验收

2026-10-21，Electron 桌面端。实施基于同日设置分类方案，导航为四个能力层、层内分类及 18 个菜单，保持连续列表，不增加折叠导航。

## 实现

- 顶部返回区域固定；菜单独立滚动。
- 一级能力标题在所属层内吸附；二级标题在距离顶部 40px 区间内随滚动连续移到一级标题右侧，保留原字号层级。各分类及能力层通过 CSS sticky 边界交接。
- 每帧合并几何读取与 transform 写入，不改变标题占位；上下滚动沿同一路径反转，没有定时动画队列或额外动画依赖。减少动态效果模式取消缩放。
- 各路由重建 Shell 时保持菜单滚动位置；直接进入不可见菜单时使其进入可视区。末分类补齐滚动空间，也可到达吸附线。
- 对话偏好迁入 `/settings/conversation`，回收站保留策略迁入 `/settings/file-trash`，复用原字段、宿主 API 与保存失败反馈；应用配置页仅保留配置管理。
- 同步菜单、页面标题、快捷键说明、首方导航白名单和现有验收脚本。
