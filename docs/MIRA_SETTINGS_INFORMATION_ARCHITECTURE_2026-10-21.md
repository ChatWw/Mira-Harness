# Mira 设置中心全量盘点与菜单划分

日期：2026-10-21。基于当前工作区源码，不代表已实施的新导航或逐项运行验收。本次仅新增本文档，不修改设置代码。

## 分类原则

先按能力的归属分层，再按用户目的分小类，最后落到菜单和页内分区。

- 底层能力：Mira 桌面宿主、全局界面、应用配置，与是否正在运行 Agent 无关。
- Agent 能力：模型连接、对话、行为约束、工具扩展及 Agent 产生的数据。
- 工作区能力：项目文件的搜索和文件生命周期，供人工操作与 Agent 工作共同使用。
- 应用与支持：独立应用目录、产品信息和反馈支持。

“数据”不是顶层垃圾桶。Agent 记忆属于 Agent，项目文件回收站属于工作区，应用配置属于底层。具体使用 SQLite、JSON 或 Markdown 不决定菜单归属。

全局／项目／当前任务是独立于导航的作用范围，不复制三套菜单。拥有同一份状态的设置只保留一个编辑入口，其他位置链接到该入口。

共 18 个叶子菜单；相比当前 16 个，仅增加“对话设置”和“文件回收站”。不为身份、语气、记忆目录、MCP、技能分别新增侧栏项。

呈现建议：一级能力层可折叠，二级小类使用轻量分组标签，三级菜单进入页面，四级为正文分区；不要给每一级都套弹出菜单。首次展开底层与 Agent；当前路由所属层保持展开，用户折叠状态保留。顶部返回区域继续固定，仅菜单区域滚动。这些为后续实现建议。

## 逐菜单、逐设置项归属

### 底层能力 / 基础设置 / 常规

- 窗口行为：关闭窗口时，保持后台运行／退出 Mira。
- 对话输入三项全部移走。当前没有开机启动、通知、语言、代理等设置，不新增占位项。
- 范围：本机应用偏好。沿用 `/settings/general` 和设置默认入口。

### 底层能力 / 基础设置 / 外观

- 主题：浅色／深色。
- 范围：Mira Shell、设置及当前应用的统一主题。
- 当前页面没有主题色、字体、字号、系统跟随选项，不把内部存储兼容字段呈现为现有设置。
- 沿用 `/settings/appearance`。

### 底层能力 / 基础设置 / 键盘快捷键

- 全局快捷键说明：搜索、设置、主题切换、关于、关闭标签或窗口、界面放大／缩小／还原。
- Agent 与工作台快捷键说明：新任务、打开项目、任务与命令搜索、侧栏切换、前台命令转后台、任务查找、终端、资源面板、完整视图、前进／后退、上一个／下一个任务、模型选择、权限模式、推理强度、发送、运行中发送方式切换、停止、换行。
- 此页主要是只读帮助，不是任意改键功能。发送快捷键是唯一相关可配置项，应链接到“Agent 能力 / 基础设置 / 对话设置”，不在此保存第二份值。
- 范围：全局帮助入口；正文清楚区分全局快捷键与工作台快捷键。沿用 `/settings/keyboard-shortcuts`。

### 底层能力 / 数据与维护 / 应用配置

- 存储概览：本机 SQLite、应用偏好数量，只读。
- 配置迁移：导出应用配置、导入应用配置。
- 恢复默认配置：菜单、微应用及偏好，包括工作台布局、打开状态和消息草稿；保留原确认和自动数据库备份机制。
- 当前导出不包含任务与消息、模型服务及凭据、权限配置、记忆、技能文件或项目文件，不能叫“完整数据备份”。
- 项目文件回收站保留天数移走。
- 范围：跨应用配置；导入／重置会影响部分工作台偏好，必须在执行前具体说明。
- 沿用 `/settings/backup-preferences`，仅改展示名，避免无必要的路由迁移。

### Agent 能力 / 基础设置 / 模型服务

- 供应商连接：选择供应商、启用／停用、API Key、Endpoint、测试连接、保存配置。
- 模型管理：同步模型列表、添加／编辑／移除模型、模型启用／停用。
- 模型能力：名称、推理能力、图片输入、PDF 输入、视频输入、上下文长度。
- 价格估算：启用价格、币种、每百万 Token 输入／输出／缓存读取／缓存写入单价。
- 内置供应商 Endpoint 当前锁定；Ollama 地址可编辑。不要将只读地址描述成任意可配置供应商，也不要把测试连接当作生产任务验收。
- 范围：本机全局模型资源库。当前任务选哪个模型仍在工作台；子智能体的独立模型在“智能体”管理，不重复搬入本页。
- 沿用 `/settings/model-config`。

### Agent 能力 / 基础设置 / 对话设置

- 输入方式：发送快捷键，Enter／Cmd 或 Ctrl + Enter。
- 上下文展示：显示上下文使用情况开关。
- 执行中交互：运行中消息处理，队列／引导。
- 三项从常规整段迁出，保留 `sendShortcut`、`showContextUsage`、`followupMode` 原字段与消费语义。
- 范围：全局对话偏好；临时发送方式、当前模型与当前任务参数仍属于工作台。
- 建议新增 `/settings/conversation`。

### Agent 能力 / 基础设置 / 指令与记忆

页内明确分四区，保留同一个菜单，避免过度拆页：

- 行为指令：全局自定义指令编辑／保存；文件路径只读。
- 身份与语气：Mira 对用户的称呼、用户对 Mira 的称呼、轻松／专业语气。
- 记忆策略：启用记忆；关闭暂停读取和自动写入，保留本地数据。
- 记忆数据：查看全局记忆、新增／编辑／删除、重置全部全局记忆；待处理记忆重试／放弃；来源、时间和路径只读。
- 范围：此页当前管理全局指令与全局记忆。项目 AGENTS.md 是文件级指令，不在此伪造项目编辑器；子智能体指令由智能体页维护。
- 记忆虽然是数据，仍归 Agent，不放底层应用配置或文件回收站。
- 沿用 `/settings/personalization`。

### Agent 能力 / 基础设置 / 权限与审批

- 手动任务权限模式：逐次确认／帮我批准／完全访问。
- 可选档位：允许选择“帮我批准”、允许选择“完全访问”。
- 范围：与输入区同步的全局手动任务权限，影响后续提交，不改正在执行的操作；自动化沿各自权限配置。
- 文件访问边界属于本页；搜索忽略规则不构成权限边界。
- 插件 Hook 的信任与撤销仍在 Hook 资源旁操作，本页不增建一份授权开关。
- 沿用 `/settings/permissions`。

### Agent 能力 / 能力扩展 / 工具与扩展

现有插件／MCP／技能三个标签保留。菜单“扩展”更名为“工具与扩展”，与独立应用扩展区分。

插件标签：

- 已安装／内置插件列表、搜索、刷新、启用／停用、移除安装登记。
- 添加本地插件。
- 浏览插件、创建插件、添加插件市场：现有动作会进入工作台扩展市场，不是本页内完成的表单。
- 详情展示版本、来源、标识、技能／命令／智能体／MCP／Hooks 及不支持项。
- Hook 审阅授权链接进入 Hooks 页。
- 移除登记保留原目录与文件，不应叫删除全部插件文件。

MCP 标签：

- 配置范围：全局／指定项目。
- 服务名称、启用状态、传输协议 stdio／Streamable HTTP／SSE。
- 本地进程：启动命令、逐行参数、环境变量 JSON。
- 远程服务：URL、认证方式、请求头 JSON；OAuth 浏览器授权。
- 新建／编辑／保存／删除、刷新、全局服务重连、连接状态及工具数量只读。
- 项目服务仅所属项目任务可用，在任务启动时连接；工作台 `/mcp` 选择当前会话服务，不能把全局启用当作所有任务自动选中。

技能标签：

- 独立技能：搜索、刷新、新建入口、导入、启用／停用、删除。
- 管理目录：共享技能目录与 Mira 旧目录只读，额外技能目录可编辑，每行一个绝对路径。
- 插件技能按来源分组，详情、状态、路径展示与文件定位；由插件维护，不伪装成可独立编辑的技能。
- 新建技能当前进入工作台创建流程。
- 删除共享技能可能影响其他应用；Mira 启用开关只影响 Mira。保留实际文件操作说明。

沿用 `/settings/plugins`，保留旧 `/settings/mcp` 的兼容定位；同一 MCP 编辑器不得产生两套配置状态。

### Agent 能力 / 能力扩展 / 智能体

- 自定义智能体范围：全局／指定项目；同名项目项优先。
- 资源操作：新建、启用／停用、编辑、删除、刷新。
- 基础配置：名称、颜色、用途说明、系统指令、读取项目 AGENTS.md。
- 模型配置：继承父任务模型／指定供应商模型；推理默认／关闭／低／中／高，按实际模型能力校验。
- 工具范围：继承角色工具／自选工具，及禁止工具列表。可选文件列出／读／改／写／删、终端、网页读取／搜索、当前任务已选 MCP；自选为空表示不使用工具。
- 高级编辑：Markdown 与 YAML，保留已有高级配置；不是所有底层字段都有表单控件。
- 内置／插件智能体：指令与工具只读；允许覆盖模型和推理强度，当前覆盖对所有项目生效，不随顶部项目筛选改变。
- 选择智能体是引用请求，由主 Agent 按需委派，不保证选中即运行。
- 沿用 `/settings/agents`。

### Agent 能力 / 能力扩展 / 自定义命令

- 范围：全局／指定项目；项目同名命令覆盖全局命令。
- 新建／编辑／删除／刷新。
- 名称、Markdown 提示词；YAML 中 description、argument-hint；正文 `$ARGUMENTS` 参数替换。
- 原有名称与作用范围限制保留。当前没有独立启用开关，不新增虚构开关。
- 沿用 `/settings/commands`。

### Agent 能力 / 能力扩展 / 事件钩子（Hooks）

- 范围：全局／指定项目／已安装插件；搜索和刷新。
- 事件：会话开始、提交消息、工具调用前、权限请求、工具调用后、工具调用失败、回复结束。
- 配置：名称、事件、直接进程／Shell 命令、匹配条件、命令、进程逐行参数、Shell、异步执行、超时 1–600 秒、运行状态说明、自定义 JSON、启用。
- 操作：新建、编辑、保存、删除、启停、信任并启用／撤销授权。
- 插件 Hook：审阅与授权、撤销授权；来源只读，配置内容由插件源文件维护；授权与当前内容绑定。
- 异步 Hook 不阻塞任务，结果不能阻止操作或改权限决定。
- 沿用 `/settings/hooks`。这是事件触发脚本，不与定时任务混为一页。

### Agent 能力 / 数据与记录 / 会话归档

- 当前“归档管理”明确更名“会话归档”。
- 搜索、按最近更新／创建时间排序、项目筛选、分组展开与显示更多。
- 单条／分组取消归档、单条／分组删除、删除当前可见结果集合。
- 这是资源管理，搜索和排序是视图操作，不是 Agent 执行偏好。
- 不把已归档会话和已删除项目文件混称为回收站；删除后具体可恢复性以既有宿主行为为准，不在分类时新增承诺。
- 沿用 `/settings/archives`。

### Agent 能力 / 数据与记录 / 用量统计

- 只读累计指标：累计 Token、峰值日 Token、最长聊天时长、当前／最长连续天数。
- 活动视图：每日／每周／累计热力图。
- 时间范围：近 7／30 日。
- 每日 Token 趋势、按模型分布、悬浮明细、刷新。
- 属于 Agent 使用记录；不是系统存储用量，也不是供应商结算账单。模型单价配置继续在模型服务里。
- 沿用 `/settings/usage`。

### 工作区能力 / 文件检索 / 文件搜索

- 工作区选择：有本地目录的项目，以及无项目但有工作目录的个人会话；刷新工作区。
- 搜索忽略规则：编辑所选工作区 `.miraignore`、从 `.gitignore` 同步、恢复默认规则、重新读取、撤销修改、保存。
- 路径、来源、未保存状态及 256 KiB 上限说明。
- 范围：所选工作目录。仅影响文件搜索，不限制浏览与 Agent 文件访问。恢复规则与同步操作需要保存后落盘。
- 沿用 `/settings/file-search`。

### 工作区能力 / 文件数据 / 文件回收站

- 从“数据与配置”迁入项目文件回收站保留天数，当前 1–30 天。
- 范围：项目文件回收站的全局保留策略；虽然现存权限配置中，不因此归类到审批页。
- 到期在清理回收站时移除，不能写成精确到点自动删除。
- 当前设置页没有回收站文件清单、恢复、清空按钮；本轮只迁移已有策略，不为新页面添加未实现管理功能。
- 建议新增 `/settings/file-trash`。复用原 `trashRetentionDays` 与原保存 API，不迁移存储。

### 应用与支持 / 应用生态 / 应用扩展

- 当前是 Mira Novel Studio 与 Mira Vision 的规划目录、搜索和禁用安装入口。
- 不是 Agent 插件，也不是已实现的应用安装管理器。
- 归入应用生态，页面和导航标注“规划中”，不计入可保存设置；后续具备安装管理能力再按真实产品扩展。
- 沿用 `/settings/app-extensions`。

### 应用与支持 / 产品与支持 / 关于Mira

- 产品介绍、本地数据与在线服务说明、当前版本。
- 复制反馈邮箱、GitHub 问题反馈、开发者主页、支持收款码。
- 这是产品信息与支持入口，没有配置项。
- 沿用 `/settings/about`，保留刚完成的页面设计。

## 不恢复的历史入口

`/settings/git` 与 `/settings/python-environment` 当前均回落常规，不因为“底层能力”这个名称恢复旧页。`aiNovel` 是模型页兼容路由；旧菜单管理、微应用管理、图标库与加载效果是遗留管理／演示文件，不等于当前正式设置入口。

此次分类不增加操作系统通知、网络代理、全局工具开关、模型预算、自动备份计划、回收站文件管理或独立应用安装能力，也不把任务运行时参数、工作台临时筛选与定时自动化编辑器迁入全局设置。

## 实施边界与验收

1. 先更新导航数据为能力层／小类／菜单，保留顶部固定和菜单独立滚动；验证当前项可见、折叠展开、键盘焦点、两侧独立滚动。
2. 仅拆出对话偏好与回收站策略，原字段、存储、默认值、保存失败回退和生效时机全部复用；验证保存、重新进入、重启及工作台消费。
