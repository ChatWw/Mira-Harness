## 1. 目标、非目标与口径

**交付目标**：一个可安装的 Mira 桌面客户端，离线首次启动可进入内置 Harness；Novel Studio 作为受管理的第一方子应用安装、切换和更新；两者共享必要的平台能力，但保留各自界面和数据。任务、审批、草稿、成果在切换或重启后按约定恢复。

**不在第一阶段**：Mira Vision 业务、任意第三方插件市场、可执行代码安装包、云同步、完整 Git IDE、媒体生成适配、差分更新、复杂多 Agent 编排及移动端。Vision 的同级空目录已预留，但尚无 Git 仓库或业务工程；本仓库只规划未启用的接入配置，不进入应用列表、设置、构建或发布。

本文件是**开发实施 PRD**，不是当前实现状态清单，也不是立即删除旧小说代码的命令。Novel Studio 与 Vision 的业务工程以后各自建 Git 仓库维护；本仓库最终仅保留其必要的平台接入配置。当前小说页面和存储仍在本仓库，须在独立包、旧作品读取及回退验收后迁出，用户数据不得随源码删除。模型供应商的数据结构、React 选型及应用包协议细节在实施时单独评审，不在这里虚构成既定接口。
