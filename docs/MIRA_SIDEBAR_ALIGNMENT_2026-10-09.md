## 必须一起修的真实接入问题

1. Vue 宿主目前用完整字符串导航白名单。带合法 query 的 `/settings/general?from=...`、历史页与技能页都会静默回到 React；只添加按钮不会接通。按校验后的 pathname 限定目标，并保留每个目标明确允许的参数，拒绝不允许的目标并显示错误。
2. 设置不带 `from` 时返回旧 `/workspace/chat`。所有 React 设置入口应带正式 React 来源；返回后恢复同一任务与草稿，不跳到旧版工作台。
