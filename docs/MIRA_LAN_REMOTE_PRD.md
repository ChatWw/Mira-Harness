# Mira 局域网移动端对话 PRD

版本：0.3 · 2026-10-21 · 已确认范围并进入首版实现，真机验收待完成

当前实现与证据见 [实现记录](MIRA_LAN_REMOTE_IMPLEMENTATION.md)。以下保留产品目标；当前已提供真实二维码与扫码直达，尚未提供大历史分页与未提交附件自动清理，不将规划目标视为已交付。

## 0. 当前交互修订（优先于下方历史方案）

2026-10-21 用户确认：侧栏只保留手机图标，灰色未启用、黄色等待、绿色在线；Tooltip 复用侧栏样式且只在 hover 出现。点击图标打开无蒙层、有阴影的弹窗，同时自动启动 LAN 服务。弹窗沿 ZCode 扫码区，保留停止、复制链接和真实二维码，去掉 Bot 栏。扫码或打开链接直接访问，不需要设备名称、验证码或电脑审批。关闭弹窗不停止服务；点击停止使现有设备会话和旧链接失效，再次打开弹窗重新启动。服务运行期间二维码有效，重启默认关闭。项目访问及移动端操作范围沿此前确认要求。

下方关于五分钟配对、等待电脑确认、允许/拒绝的段落为历史方案，已被本节替代。当前仍保留随机链接凭证、设备会话和同源/项目边界检查，扫码自动完成凭证交换。

## 1. 产品目标

让同一局域网内的手机或平板通过浏览器连接正在运行的 Mira，浏览电脑上的项目与对话，继续提交任务、查看执行结果和处理审批。任务始终在电脑执行，移动端不另起 Agent，不要求云端中继、智谱账号或 Bot。

成功标准：扫码并经电脑确认后可进入任务；双端内容一致、选中会话互不干扰；断网恢复不重复执行；设置、终端与右侧面板能力在服务端不可访问。

## 2. 已确认要求与本版建议

已确认：仅局域网；手机与平板浏览器；简化侧栏和对话；可以聊天和处理工作；禁止右侧面板、交互终端与设置；先审 PRD 和原型，确认后实现。

以下为建议，等待本轮确认：

- V1 同时允许一个移动设备在线，另一设备连接时由电脑明确替换；断线重连保留同一设备身份。
- 每次手动开启服务；重启 Mira 后默认关闭。停止服务立即断开所有设备并使凭据失效。
- 一次性配对链接有效 5 分钟，扫码后仍需电脑确认；确认界面显示浏览器、设备自报名称、来源地址和短验证码。名称不作为可信身份。
- 可访问范围为项目空间：展示电脑已有项目空间及其中的任务，不展示项目空间外的独立任务；不额外设置逐项目勾选授权。项目移除或任务移出项目空间后立即失去访问资格。归档任务首版不展示。
- 手机可选择电脑已启用模型及该模型支持的思考强度；不读取密钥，不编辑供应商，不提供跳转设置入口。允许手动切换当前任务权限档位，但不能修改电脑全局权限策略，电脑禁用的档位不可选。
- 输入框“＋”仅提供引用手机文件、上传照片（系统选择器可提供相册／拍照）；不提供技能、插件、命令、电脑文件引用等其他加号功能。不开放下载、文件预览、剪贴板读取、通知订阅或 PWA 安装。
- 不开放任务删除、项目管理、插件管理、自动化管理、跨设备持久信任与公网访问。

## 3. 用户与场景

个人用户在同一家庭或办公室网络，用手机查看长任务进展、补充指令、批准必要操作；平板用于持续阅读与对话。电脑必须运行 Mira、保持唤醒且网络可达。电脑锁屏或最小化是否继续执行沿现有运行时规则；系统睡眠时手机显示离线，不承诺唤醒电脑。

## 4. 权限边界

| 能力 | 移动端规则 |
|---|---|
| 项目／任务列表 | 只读项目空间及其任务，排除空间外任务，搜索按标题，分页加载 |
| 对话历史 | 只读项目空间内任务，长历史分段加载 |
| 新建／发送 | 可在已有项目空间新建任务、提交文字与手机附件、追加指令 |
| 模型／思考 | 选择电脑已启用模型及支持的思考强度，无设置跳转，密钥留在电脑 |
| 当前任务权限 | 手动切换电脑已允许的权限档位；不修改全局策略，运行中不追溯改变已执行操作 |
| ＋ 附件 | 只允许手机文件与照片；不开放其余加号功能 |
| 运行中输入 | 进入同一持久消息队列，显示待发送状态，允许撤回尚未开始的本人输入；停止运行后余下队列暂停，手动继续 |
| 停止任务 | 允许，绑定当前 runId；过期请求不影响新运行 |
| 审批／提问／计划确认 | 可处理当前授权任务的待处理项；双端抢答首次有效 |
| 对话与文件结果 | 保持电脑端对话显示；保留右侧面板入口的原有呈现，点击拦截并 Toast 提示“此功能需要在电脑上使用” |
| 设置／供应商／全局权限配置 | 页面与接口均禁止 |
| 交互终端／PTY／资源面板／浏览器面板 | 页面与接口均禁止 |
| Agent 工具执行 | 延续电脑既有权限，可按任务需求执行命令和修改文件；与交互终端区分 |

禁止依靠 CSS 隐藏完成权限隔离。手机手工构造请求、改 sessionId、改项目 ID 或放大到桌面宽度均不能越权。配置密钥、环境变量、完整模型配置、终端输出接口、原生路径操作不进入远程 API。

## 5. 信息架构与界面

### 5.1 电脑端

工作台侧栏底部增加“移动端连接”入口；管理弹窗包含开关、局域网网卡／地址选择、配对二维码与复制链接、项目空间范围说明、待确认设备、在线设备、断开和停止服务。此入口不出现在手机。

首次启用：确认项目空间范围 → 启动 → 选可达网卡 → 显示地址及真实二维码 → 手机访问 → 对照短验证码 → 电脑允许／拒绝 → 手机进入任务列表。没有有效网卡、端口占用或系统防火墙阻挡均给出明确错误；不自动修改防火墙规则。

重新生成链接使旧链接立即失效；拒绝仅拒绝该次请求；断开当前设备撤销设备凭据，重新连接需再次配对；停止服务同时撤销链接及设备会话。离线设备不得占据唯一在线席位造成永久阻塞。

### 5.2 手机

连接页：电脑名称、局域网地址、连接状态；等待电脑确认时不返回项目／消息数据。拒绝、过期与服务停止分别显示说明与重新连接操作。

任务页：顶部电脑名称与连接状态；新建对话；项目分组；任务标题／时间／运行状态；按标题搜索；底部断开连接。没有设置、自动化、市场、终端、项目管理入口。

对话页：返回任务列表、任务标题、连接状态；消息／运行摘要／文件结果文字；审批或提问区；输入框、“＋”附件、模型、思考强度、当前任务权限、发送／停止；运行中显示排队输入。手机返回键先返回任务列表，不关闭服务。

### 5.3 平板

宽度达到 768px 使用左任务列表＋右对话两栏；窄屏使用列表／对话两页。两种布局始终具有同样的移动端权限；不恢复桌面右侧面板或终端。软键盘出现时输入区可见，采用动态视口和安全区，页面不横向溢出。

## 6. 核心行为与同步

1. 手机选中任务不改变电脑当前选中任务。双端写入共享同一个任务与消息队列。
2. 消息提交携带稳定 submissionId；超时后显示“确认发送结果”，使用同一 ID 查询／重试，不生成重复消息。
3. 已接受消息即使手机断网仍在电脑继续执行；未确认接受的消息不得显示为已执行。本地草稿与正式队列明确区分，切换任务保留各自草稿。
4. 事件按会话／运行排序与去重；首次连接先建立快照与后续事件的连续边界，禁止快照覆盖其后的增量。
5. 重连重新鉴权并恢复当前任务、历史、当前运行、待审批及队列。检测事件缺口后刷新权威快照；不承诺无限事件回放。
6. 短暂离线时显示连接条，禁止新发送和审批，保留草稿；恢复连接后先同步再允许操作，不自动提交未确认的草稿。
7. 审批结果由宿主提交成功后确认；另一端已处理则刷新状态，不能覆盖。拒绝沿用现有运行时后续行为。
8. 手机订阅慢或断开不得阻塞电脑事件；设独立有界缓存，超限转快照同步。
9. 任务归档／删除、任务移出项目空间或电脑停止服务后，手机及时清除该项可访问状态，后续请求也必须拒绝。

## 7. 网络、配对与数据保护

电脑提供独立静态移动页面及受限网关；静态资源随应用打包，不从外网 CDN 加载。仅监听用户选定的私有局域网接口；校验实际连接地址、Host 和 Origin，默认拒绝公网来源和代理转发推导的伪造来源。V1 IPv4 私网优先，IPv6／VPN／访客网等另行评估，不以 0.0.0.0 加 IP 字符串判断代替完整边界。

配对采用高熵一次性令牌，优先放 URL fragment、交换后从地址移除；服务端绑定待配对请求并限速，超时失效。电脑确认后签发独立短期设备会话，支持撤销和轮换；不复用 Electron grant 或模型凭据。防跨站请求、WebSocket Origin 校验、请求体大小上限与会话授权检查必须落在网关。

V1 建议本地 HTTP／WS（无需证书安装），但它不防同网恶意监听，不能宣称端到端加密。“仅在可信局域网使用”需出现在电脑启用说明。HTTPS／WSS 会引入本地证书信任或受信域名方案，作为评审待定项，禁止静默忽略浏览器证书错误。

HTTP 私网地址可能不支持浏览器部分安全上下文能力；V1 不依赖 Service Worker、通知、麦克风或异步剪贴板成功。复制链接失败时可手动选取地址。不得通过 UPnP、穿透或公网 relay 绕过局域网范围；路由器是否被用户另行配置端口转发不在应用可绝对保证范围内。

浏览器页面可缓存已显示内容，不能承诺从设备截图／浏览器历史中撤回数据。服务端撤权后禁止继续读取，页面清理缓存；敏感响应 no-store，凭据不写日志和原型 URL。

## 8. 状态与异常

| 状态 | 展示与可用操作 |
|---|---|
| 服务关闭 | 电脑可开启；手机连接失败，提示回电脑开启 |
| 无项目空间／网卡不可用 | 不启动，显示处理方式 |
| 等待扫码／链接过期 | 显示有效期或重新生成 |
| 等待电脑确认 | 手机只等待；电脑允许／拒绝 |
| 已连接 | 列表、历史、提交与任务交互可用 |
| 临时断网／同步中 | 显示重连，保留草稿；暂停写操作 |
| 连接被撤销／被替换 | 清空授权视图，提示重新扫码 |
| 任务不存在／授权撤回 | 返回列表，取消订阅，草稿可复制保存 |
| 模型不可用／运行失败 | 原任务内显示错误；不跳转设置，提示电脑端处理 |
| 没有任务／搜索无结果 | 给出新建入口／清除搜索 |

## 9. 实现边界与复用方案（非已实现）

复用 HarnessRuntime、会话存储、消息队列、现有权限与计划协调器，以及可拆分的消息渲染与输入组件。新增受限远程 API、配对服务、独立移动入口和 LAN transport。现有 FirstPartyHarnessHost 依赖 MessagePort，不能直接在手机复用；现有 grant 绑定 WebContents，不能发给手机。

事件发布需从指定 sender 发送扩展为宿主权威事件订阅；队列与运行时中的 WebContents 依赖需要明确适配，不能伪造 WebContents。禁止为手机复制一套运行时或持久队列，禁止把 platformIpc 整体映射成网络 RPC。

建议命令集合：projects.list、sessions.list/get/create、models.options（脱敏）、messages.submit/status、queue.list/withdraw、runs.abort、interactions.list/respond、connection.status/disconnect。确切命名在技术设计阶段确定；每项检查设备、项目空间、任务归属和参数结构。后台任务引用和日志输出需构造移动投影，避免无意暴露隐藏功能。

## 10. 原型范围

配套 `prototypes/lan-remote/index.html` 为离线交互原型，全部数据虚构。覆盖：桌面启停与项目选择、模拟扫码、允许／拒绝、手机列表搜索、新建／切换任务、发送与排队、审批／拒绝、停止、断网重连、过期、撤销、手机／平板切换。二维码为明确标识的示意占位，不可扫码，不创建服务或真实连接。原型不代表产品已实现，也不验证 LAN 安全或 runtime 同步。

## 11. 验收场景

- A01 同网真实手机扫码，电脑允许后可见项目空间；未允许前无会话数据。
- A02 拒绝／链接过期／旧码／重复消费令牌均不能进入。
- A03 项目空间外的任务 ID、设置、终端、文件面板与任意未知命令全部被服务端拒绝。
- A04 手机与电脑可看同一任务的增量；手机选任务不改变电脑选择。
- A05 双端同时发送按宿主接受顺序入队；重试同一 submissionId 不重复执行。
- A06 运行时断网、后台挂起、刷新后恢复快照和审批；草稿不会自动发送。
- A07 双端同时审批只成功一次；旧 runId 停止请求不影响新运行。
- A08 手机断开不取消任务；电脑撤权后所有旧请求／订阅失效。
- A09 平板始终无设置与右面板；手机横竖屏、软键盘、安全区无操作遮挡。
- A10 网卡切换、防火墙、电脑休眠、服务重启均显示真实连接状态。
- A11 原型不触发真实任务、网络配对、终端或配置写入。

## 12. 非功能验收目标

以下是目标，不是当前测量结果：同网常规条件首屏可交互 ≤3 秒；任务增量可见延迟 P95 ≤1 秒；短断网恢复后 ≤5 秒完成当前任务重同步。测试需记录真实网络、设备、历史规模和耗时；大历史分页并限制事件缓存，不一次加载整个数据库。键盘与读屏可操作、正文对比度至少 4.5:1，危险操作与状态不能只靠颜色区分。

## 13. 分阶段交付与评审关口

1. 本轮：PRD＋离线交互原型，用户确认范围、配对机制及页面流程。
2. 技术设计：网络边界、脱敏 DTO、运行时适配、事件顺序与重连协议；先列威胁与失败测试。
3. 实现：网关与配对 → 双端同步 → 简化移动 UI；不夹带 Bot／公网／设置能力。
4. 验收：真实手机与平板、Windows 防火墙、断网／后台／并发操作及越权请求测试。

首版采用：一个设备在线、5 分钟一次配对、HTTP 可信局域网方案。已确认：仅项目空间、模型与思考可选、加号仅手机文件／照片、当前任务权限可切换。用户已确认先做一版，当前进入实现与验收阶段。

## 14. 0.2 评审修订：附件与任务选项

- 项目空间是服务端访问边界，不只是列表过滤。无项目归属任务及其消息、附件、事件不可通过直接 ID 访问。新建对话明确选择项目空间。
- 模型变化后重新计算思考选项，不支持思考配置的模型不显示该控件；不保留无效强度。不提供“添加模型／配置模型／去设置”。
- 权限切换作用于当前任务，须宿主确认后显示成功；双端同步。生效时序沿电脑既有运行时规则，已执行工具不可回溯；若当前运行不能即时变更，明确提示下次提交生效。已禁用档位服务端拒绝。
- 文件引用意味着将用户在手机系统选择器中选中的内容上传电脑，不是传递手机本地路径。照片只从用户主动选择的文件读取，不遍历相册。禁止手机指定任意电脑保存路径。
- 附件生命周期：选择 → 待上传 → 上传中 → 成功／失败 → 随消息提交；失败可重试／移除，未成功禁止发送。离线保留附件草稿且暂停上传，恢复后手动重试；提交重试不得重复导入。允许仅附件消息。
- 文件类型、数量、大小与模型媒体支持沿电脑附件规则，由宿主下发限制并校验；不支持的类型给出原因。网关限制请求体、规范文件名、生成存储标识，未提交临时附件超时清理；撤权中断上传。
- 原型使用系统文件选择器，仅在内存保存文件名／大小，不读取内容或真正上传；附带“示例照片”按钮供没有文件的评审者体验。上传进度、失败重试与模型能力变化由后续实现验证。
- 新增验收：无项目任务直接访问拒绝；模型／思考切换与桌面一致；加号只有文件／照片；离线上传禁止；超限／不支持附件拒绝且可移除；仅附件发送；权限切换成功／被电脑策略拒绝均可识别；以上操作均无设置入口。

## 15. 对话一致性与面板操作拦截（已确认）

移动端复用电脑端对话渲染，保留消息、Markdown、思考／工具执行记录、文件结果卡、计划和交互请求的显示，不另造一套精简内容投影；只适配窄屏换行、触摸与输入区。仍需避免输出密钥等内部配置。

所有原本会打开右侧面板的入口，保留原有显示并统一拦截：文件／附件预览、文件链接、变更详情、计划／子任务／工作流详情、模型轨迹、浏览器及其他资源标签等，具体以实际导航目标为准，不以链接文案匹配。拦截后不创建标签、不请求对应资源、不启动本机程序，Toast 原文固定为“此功能需要在电脑上使用”。设置和交互终端仍没有入口。

审批、计划确认、停止运行等直接影响任务的内联操作继续可用，不能因同时存在详情入口而一并禁用。普通外部网页链接不自动归入面板拦截，按现有链接策略处理，不赋予本机访问能力。网关同时拒绝面板相关 API；Toast 只是交互反馈，不替代服务端权限。

新增验收：逐一点击电脑对话中各类面板入口，只出现指定 Toast；重复点击可重新提示；键盘触发同样拦截；不创建面板或发起预览请求；对话正文与电脑同一会话一致；内联审批／问答正常可用。HTML 原型只示意文件、变更及执行详情入口，完整渲染一致性在实际复用组件时验收。
