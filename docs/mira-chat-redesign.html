Mira Harness · 对话页面重设计方案

本稿按项目当前默认主题出图：monochrome 预设（theme.ts 中 DEFAULT_PRIMARY_PRESET_ID = 'monochrome'），亮色模式主色 --cp-primary = #080808（近黑），由 theme store 运行时注入。SCSS 里的 $primary: #06b6d4 仅为编译兜底、非运行时默认。落地时全部引用 var(--cp-primary)，用户切换靛蓝/紫/蓝/青/绿预设时 UI 自动跟随；卡片点缀色使用不随主题切换的语义色板（蓝/紫/琥珀）。

01

新对话页面 —— 保持 Codex 式骨架，调字号 + 加色彩点缀

  • 骨架不动：居中 Hero → 快捷卡片 → 输入框，间距收紧让卡片与输入框成组
  • 卡片文字放大：标题 13→14.5px，描述 11→12px 且提亮（tertiary→secondary）
  • 色彩点缀用语义色板（蓝/紫/琥珀），黑白主题下不显寡淡，切主题也不受影响
