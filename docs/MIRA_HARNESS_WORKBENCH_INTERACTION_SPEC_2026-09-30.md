### 5.3 操作

添加项目使用单次目录选择，在途重复点击不再调用；取消不改项目、任务或草稿。成功读取实际项目清单后展开父区和目标项目，已有隐藏项目恢复原身份，不附带创建或选择任务。目录消失显示“所选目录已不存在，请重新选择目录后重试。”，未知内部错误使用安全通用说明；反馈在侧栏就地展示，即使主区域处于插件市场也可见，重试清旧反馈。成功及F5保留原任务、独立草稿和模型；限定生产Electron验证范围见首屏记录11:48。

目录不可用项目在折叠/展开时均显示警告，键盘/悬浮可读取完整目录及恢复原因；菜单明确禁用新建、文件树、文件管理器与终端打开。历史仍可阅读，改名/隐藏不依赖目录存在；改名后读取实际项目列表并更新名称及可用状态，不重开无关任务。目录恢复后重新加载工作台可清除警告。同一行菜单打开期间标题/状态/动作Tooltip暂停，关闭后不恢复旧悬浮提示，避免提示覆盖菜单。

项目/组行的新建、文件树和更多在闲置时不占标题宽度，hover、键盘焦点或更多菜单打开时显示；任务行更多同样在菜单打开期间保持可见及定位。菜单生命周期使用独立menuOpen，不依赖与Tooltip共享的data-state。Header和任务行更多提供统一Radix悬浮/键盘提示，Escape关闭菜单回到触发按钮，正文草稿保持。

- 单击打开会话；右键或 `...` 打开上下文菜单：重命名、置顶、标记已读、移动项目、归档、复制工作目录/会话 ID、打开终端/文件管理器、删除。
- 侧栏重命名等待真实保存成功才退出；失败保留草稿并显示错误，保存中防重复提交。中文合成输入的 Enter/Escape 不提交或取消，旧请求不能关闭随后重新打开的编辑器。
- `⌘/Ctrl+B` 切换侧栏，收起后仍有效；普通 PlainText Composer 同样可用，文件编辑器/终端保留各自 B 绑定。会话开关 hover/focus 显示当前展开/收起动作和快捷键，模态/菜单、IME、长按 repeat 与已消费事件不触发工作台操作。
- 任务行 hover/focus 替换时间为实际快捷操作。分组非置顶行提供文件树、手动移到根顶部、X 直接归档；项目/置顶/时间线行使用同一归档按钮就地红色确认，离开 hover 保留，Escape/行外点击/打开菜单取消。点击获得按钮原生焦点，不启动排序或打开对话；在途单飞、失败保留确认与可见重试，审批/待输入保留状态和更多菜单。
- 归档成功移出活跃列表但保留草稿/模型；迟到响应不覆盖新任务/草稿，成功后列表刷新失败用全局提示。归档不等于永久删除，不触发删除 owner 清理。
- 任务文件树仅替换侧栏，项目用 projectId、个人目录用捕获的 sessionId，不创建/选择会话、不等待当前草稿保存，自动化主视图保留。其他 owner 的树不借当前任务预览/引用/编辑器；当前个人树接监听并在换 owner 释放，跨 owner 预览及项目/其他任务自动监听待后续实现。
- 组动作提供组内新任务草稿、名称/颜色、成员移入/移出和解散；解散只清组关系、保留对话。组新任务在组首显示临时行，根入口在根首显示，临时行不提供真实任务菜单或拖拽。重复入口复用草稿，切项目迁移同一 owner 并保留冻结附件；关闭只隐藏入口、清临时分组，保留正文/附件/配置供复开，不归档或永久删除。
- 草稿需要附件/配置时准备 `prepared` owner，不进入列表、搜索、历史、计数或项目最近时间。只有宿主实际接纳首发后提升为 `accepted`，进入发送时捕获的组首；原组删除则根首。失败保留草稿，在途/确认未知不创建另一个 owner，迟到确认不能抢导航或清另一个任务的输入。位置偏好保存失败仅重试保存，不重发消息。
- 刷新恢复统一经 Workbench 导航事务，等待 hydration；无 Shell 快照、无正式 fallback 时也恢复原 prepared 草稿。prepared 不写正式 active-session/导航历史，接纳后才成为正式任务。显式清除胜过迟到 hydration；首发捕获正文/附件/项目/模型/计划，确认只清同一提交的输入。
- 项目行在 hover/focus 提供新任务、文件树、更多；菜单提供真实重命名、目录/终端打开、手动排序与隐藏。隐藏/恢复只改入口，绝不调用会删除会话/回收站/自动化的旧 `deleteProject`。原生目录添加取消不改数据，失败可见；选择成功展开父区和目标项目，已有项目也应进入可见列表，不改其排序、不附带创建任务。
- 分组视图在手动排序时允许任务跨组、进入空组及移入根列表；根任务与组可以交错，折叠组前后及展开组首尾按移动方向选择根/组内落点。置顶与项目视图维持各自范围；拖动组时只临时折叠，结束/取消恢复原折叠偏好。键盘使用 Space 开始/落下、方向键移动、Esc 取消，不能只支持鼠标。
- 拖拽预览不写偏好；落下以同一快照保存组成员、未分组顺序与根交错顺序，Esc 零写。空组停留不能循环渲染；预览移动分组后要重测独立 head/tail 落点。保存失败回滚，但迟到旧失败不能覆盖后续本地修改。这些是当前交互合同，实际验证状态单独见首屏总文档。
- 归档按钮打开列表、工具栏 `X` 退出；分页、打开、恢复、二步单项永久删除有 loading/error/empty。工具栏 `…` 提供“删除所有归档任务…”，先读取主进程 grant 绑定的完整快照数量；不是仅删除加载的 50 条或当前筛选，含置顶/隐藏项目。取消/Esc 不删除，退出/切自动化/设置不被晚响应重开确认。
- 确认一次消费快照，写入时重新检查归档及运行/队列/未确认提交；分别反馈删除、跳过和失败。成功目标清附件/草稿/本地缓存，保护迟到保存和 hydration；失败或其他 owner 内容保留。后续只读刷新失败单独重试，不能重复提交删除；相关自动化对象保留。当前真实 UI 删除后列表读取两次，不声称一次刷新。
- 控件和选中态使用黑白/灰语义；运行状态同时提供文字/图标，待处理 amber、失败 red、完成 green，不用 teal 作为通用主操作色。

## 6. Task Thread

### 6.1 Header

- Header 为 48px 单层应用标题条，左侧提供会话栏、可达的工作目录信息、当前任务标题与任务菜单；空任务不重复显示大标题。
- 项目/工作目录归属于任务上下文和 Composer 项目条，不再用两行大标题重复占据阅读区。
- 目录菜单提供完整路径、复制和受控文件管理器打开。任务更多菜单复用侧栏真实操作；不加入没有数据的 branch/云分享/分叉。
- 标题重命名保护中文合成输入，失败保留编辑草稿；提交绑定发起会话和本次编辑，迟到结果不能关闭或覆盖另一会话、重新打开的编辑框。
- 右侧提供外部编辑器、终端与工作区开合；状态和左侧文件树入口不在 Header 常驻，按用户要求归摘要/侧栏。变更/浏览器从 launcher/摘要进入，不堆叠占位图标。
- 任务状态在执行记录/摘要呈现：`等待任务`、`正在执行`、`等待确认`、`已完成`、`已停止`、`执行失败`。

### 6.2 消息与任务轨迹

- 用户消息靠右，助手消息靠左，正文阅读宽度控制在 65–75ch。
- 两个及以上真实用户轮次出现轮次 rail，按钮使用 TanStack Virtual 仅挂载可见范围，Radix Hover Card 展示实际 prompt/response 片段；点击先挂载目标再定位，滚动同步当前轮次。方向键/Home/End/Page 导航保持键盘焦点，hover 不抢正文或 Composer 焦点，迟到片段不跨任务。正文历史轮次另行虚拟化，运行末轮保持正常流；查找/rail/摘要复用定位。持有焦点或正在编辑的轮次保留挂载，取消编辑或焦点离开后释放对应保留。阅读记忆按会话/root 在 renderer 内保留，不承诺进程重启恢复。
- 历史首次挂载不逐行同步读取布局，实际行高由ResizeObserver提交；恢复/跳转继续批量实测，零宽观察值不污染缓存。主/旁阅读锚点按各自会话保留，收栏/重开、真实分栏宽度变化和父任务导航后分别恢复；虚拟总高不能因隐藏时换行膨胀到百万级。该行为已完成明暗隐藏宿主长历史验证，原生拖动与显示帧验收独立保留。
- 用户附件置于正文上方，图片为 80px 缩略图、文本为紧凑条目；不可变附件打开第 7.4 节预览。旧相对工作区引用仍打开受控预览，绝对路径不扩展为任意文件读取；附件-only 不画空文本气泡或空正文复制。
- 当前 run 即使正文尚空也投影到助手时间线；运行/等待确认用 live 行，结束后折叠为 completed/failed/stopped/partial 及实际完成数/耗时。
- 父任务 text/reasoning/tool parts 按真实事件顺序呈现；公开思考可折叠，工具显示真实有界参数/输出及审批、失败、取消。展开状态按会话、run 与条目身份隔离，虚拟化卸载再挂载后恢复。没有 parts 的旧历史按兼容路径渲染，不补造思考或参数。
- 工具中的文件入口打开受控工作区相对路径；工作区内的绝对路径先规范化，工作区外目标不提供可点击预览。文件按钮不触发父工具详情开合。
- 读取、列目录、搜索和抓取默认显示轻量摘要，成功状态不重复占位；悬浮或键盘聚焦显示独立调用记录入口。连续两项及以上明确只读工具合并为“查阅”，包括公开完整命令中所有段都能保守识别为读取/列目录/搜索的 bash；动态展开、重定向、脚本、写入或混合执行仍显示为“执行”，此分类仅用于展示，不改变授权。计数按真实调用次数，复合命令只算一次。

- 模型菜单按 provider 分组并可搜索，当前项有选中状态；模型具备 reasoning 能力时提供推理档位选择和快速循环控件，不支持时隐藏入口。模型及有效档位按会话保存，切换 A/B 不继承其他会话的选择，恢复时忽略不可用模型和非法档位。
- 模型供应商→模型采用 Radix 两级菜单：32px 行、当前供应商及模型勾选、子菜单不超过可用空间/288px 高，管理入口保持可达。搜索跨供应商显示结果，图片/推理图标只取已配置能力；禁用供应商/模型及空 ID 不显示。搜索上下键进入列表，左右键进入/退出子菜单，Enter 选择；Escape 关闭整组并回所属 Lexical，外部交互保留外部焦点，管理模型跳转不抢回输入。IME 组合与 keyCode 229 不导航、选择或关闭；供应商 ID/模型 ID 用二元组区分，避免含冒号身份冲突。选择和推理档位沿用下一次提交及会话偏好，不修改已执行轮次。
- 计划模式是权限菜单内独立开关，权限档位是互斥选项；计划开关与权限不能互相覆盖。
- 三档权限有说明文字，并受统一设置中的档位启用策略约束。选择仅保存在所属 Composer 草稿，运行中可修改，不立即改会话、不锁输入、Header 不显示草稿权限；主任务与旁路独立恢复。
- 提交携带明确 `permissionMode`，Electron 在新接纳时校验并随队列消息冻结。该消息实际开始时，权限和用户消息同一次保存；已运行轮次保持原策略，权限不匹配的引导转为待发送。未知 ACK 重试保持原权限/ID，明确的档位禁用拒绝保留正文并允许换档重新提交；撤回编辑恢复原消息权限，匿名草稿准备时转移到新 owner。旧宿主不支持该提交选项时沿用原会话配置流程，旧直接运行入口仍沿用动态全局权限。
- 快捷建议只在空输入时显示，点击后填入草稿，不直接提交。
- Slash 菜单支持上下键、Enter、Esc 和鼠标选择，列表为空时显示可恢复提示。

### 7.4 图片与文本附件（2026-10-10）

- 支持 PNG/JPEG/GIF/WebP 与 UTF-8 文本；最多 12 个引用，图片单张 20 MiB/合计 40 MiB，文本单个 256 KiB/合计 1 MiB。原生选择、拖拽、粘贴共用限额，超过 15Ki 字符的文本粘贴转附件；电子表格文本优先于剪贴板生成的截图。PDF/视频/Office 尚未接入，不把文件预览能力当模型输入。
- `attachments.import/select/stage/get/save` 经第一方双解析/授权桥进入宿主；令牌按会话隔离，`stage` 仅接授权工作区相对路径。导入时冻结实际字节，后续文件修改不改变已选附件；图片只在附件表保存一次，消息/状态/会话 JSON 只携带元数据，在模型/压缩边界读取字节。
- Composer 图片 48px、历史图片 80px。点击进入当前输入/消息的图片组，左右按钮/方向键循环，50–300% 缩放后拖动；切项重置位置并释放 pointer capture。加载/读取/解码失败有单项重试，缓存图片重试不被后来的 effect 留在 spinner；隐藏/换会话立即关闭预览。
- 保存按钮使用系统保存对话框；renderer 不能传目标路径/内容，宿主复查会话/授权后写出冻结字节。取消不丢草稿，错误不落在后来切换的图片/任务。关闭恢复原缩略图焦点，预览内的快捷键不切换 Composer 模型/权限或停止运行。
- 不支持图片的模型在入队/写历史前拒绝，保留完整草稿；选择支持图片的模型后可直接重试，断线不确定 ACK 仍沿既有提交身份防重复。
- 启动保留 accepted 空任务，以及被 `draft.sessionId`、正文/附件草稿或未确认提交引用的 prepared owner；metadata 的会话根不单独保护没有附件引用的孤儿附件。仅启动时回收无历史/持久 fileDrafts/recoveries/submissions 引用的暂存附件；损坏 owner 保留其附件，未知整体格式跳过清理。运行中移除暂不回收，SQLite 页可复用，不承诺文件立即变小。已 ACK、尚未执行的队列仍为进程内状态，不承诺退出后保留该队列或其无持久根附件。

## 8. Workspace Side Pane

### 8.1 通用行为

- 顶部是面板 tab：`任务活动`、`文件`、`变更`、`终端`、`浏览器`。新会话默认没有打开的 tab；无标签时显示“打开标签页”，顺序为文件、变更、终端、浏览器、任务活动。launcher 按面板容器宽度响应：小于 480px 为单列资源行，至少 480px 为自适应卡片。选择资源后创建/激活动态 tab，所有 tab 均可关闭。
- 每个 tab 有明确 active、关闭、溢出菜单状态，可拖拽排序；排序保持原选中，Enter 激活标签，Space 开始键盘拖拽。中键关闭非活动标签不改变当前选中；右键可关闭当前、其他或全部标签，并恢复最近关闭的标签。
- 标签概览为288px搜索浮层，搜索框固定、列表最大320px且受可用空间约束。按打开/最近关闭分组，支持标题/类型/路径/URL多词搜索与标题优先的稳定排序，展示类型和路径/URL提示。同名项使用资源ID区分，方向键/Enter切换或恢复；就地关闭不激活、不退出搜索，键盘关闭后回搜索，迟到回执不抢新输入焦点。Escape回概览入口，点击外部输入保留该处焦点。打开/关闭时间来自真实状态转换，旧偏好没有时间就不显示，恢复重新记录打开时间。
- 关闭当前 tab 后优先选中原位置右侧邻项，末尾则选左侧；没有剩余标签时回到 launcher。标签和最近关闭历史按会话隔离，恢复终端创建新 PTY，不恢复已关闭进程。
- 面板标题区显示当前会话标题和工作目录，避免在不同会话间误操作。
- 子任务使用独立可关闭页签，保存 session/run/child 身份；关闭、恢复和排序保留归属，标签与关闭历史不能跨会话串用。
- 面板空态必须说明“这里会出现什么”和下一步动作，不能只留大面积空白。

### 8.2 任务活动

- 入口保存明确 runId，顶部展示该次运行的实际状态、运行时长和步骤；历史运行不自动切到最新一次。
- 下方按时间显示该 run 的活动和工具记录，工具详情可折叠；错误提供实际已接入的操作，不虚构重试能力。
- 待审批时把审批卡置顶，允许在面板和 Thread 两处进入同一确认动作，但只能触发一次。
- 新子任务页签显示该 child 的实际公开有序正文、思考和工具调用，复用主对话渲染器；用户气泡只显示公开任务，不显示系统提示、临时附件 prompt 或私有引擎消息。正文存在时不重复显示最终报告；无正文时才使用报告 fallback。
- 子对话滚动、跟随/暂停、回到底部及展开记忆按 session/run/child 独立，父对话阅读位置不受影响。悬浮摘要显示实际活动、文件、时间与累计用量，按实高预留顶部空间；终止/失败保留已记录内容。旧记录没有 parts 时仍显示真实活动/报告，不补造历史对话。
- 子消息流以 250ms 合并发布，工具/消息/终态边界立即落盘；调用身份包含 child、response 与同响应序号，重复 provider ID 不串记录。父任务终态快照等待子任务关闭；重启仅中断相同 run/child 的活动和待完成工具，保留完成内容。

### 8.3 文件

- 左侧文件树替换任务导航，右侧每个完整相对路径是独立只读预览 tab；返回任务保留预览。树为 28px 虚拟行、12px 缩进，目录懒加载、刷新/重试、单一 Tab 入口和完整方向键/Shift+F10 操作；预览工具栏为 40px。
- 28px 搜索框以 120ms 防抖调用 `files.search({ sessionId, query, refresh? }) -> { entries, truncated }`，搜索整个当前授权目录内经 `.miraignore` 过滤的候选，包含未展开节点；默认排除 `.git/`、依赖等目录，空规则可放开。保留 Mira 既有 dotfile/隐藏目录候选，不另加上游候选黑名单。按上游 basename/相对/绝对路径 fuzzy scoring 返回前 1000 项；截断有提示，不声称只有这些匹配。
- query 修改立即清旧结果；epoch/请求序号拒绝旧会话、root 或 query 响应。无匹配、搜索失败和重试各有状态；不可读目录令整个搜索失败，不展示部分结果。刷新强制重扫缓存。
- 打开搜索中的文件保留 query；清除搜索返回树并定位选中文件。打开搜索中的目录先清 query，再以 `revealPath` 强制刷新 root → 祖先 → 目标目录，展开并定位，包括搜索后新建但旧树尚未包含的目录。
- 主进程按 realpath/`dev:ino` 隔离 root；60 秒 TTL、4-root LRU、估算累计 128MiB 缓存；扫描最多 8 个目录并发、约 8ms 工作预算后让出事件循环。返回候选前重新验证路径仍在当前 root 和类型一致，这些预算不构成硬耗时承诺。
- 文本预览提供刷新、Markdown/源码、自动换行、复制相对/绝对路径与内容、加入对话和外部打开；加入只合并附件并聚焦输入，不发送。文件读取失败有具体可恢复提示；监听、外部编辑器、图片与 Git 状态叠加见第 8.8–8.11 节，音视频/Office 尚未实现，文件保持只读。

### 8.4 变更

- 按消息/run 分组显示新增、修改、删除统计。
- 点击文件打开 diff；默认折叠大段上下文，保留文件名、行号和变更统计。
- 完成任务后，变更面板是成果入口之一，不能只在消息里显示一行链接。

### 8.5 终端

- 每个终端在右侧统一资源栏中拥有一个标签和一个 PTY；标题为工作目录名，重复时增加序号，不再显示内层终端标签栏或常驻连接头。创建中显示连接状态，首段输出不能丢失。
- 实例按主会话/资源身份维护；切换标签、主任务或隐藏工作区保活，真正关闭资源才释放对应 PTY。页签菜单可重启指定终端；最近关闭恢复同一资源身份但新建进程。旧 `terminal` 偏好继续可读，页面刷新不恢复旧进程。
- 标签统一按 156px/最小 60px 等宽收缩，选中态不额外撑宽。关闭后焦点回相邻选中标签或空栏标签入口；异步关闭时用户已转去输入则保留新焦点。终端内容只保留单层 12px 内边距，不继承其他 inspector section 的额外 padding 和底边线。
- 输入数据保持 xterm 原始字符，包括 CR、空格、Tab 和 NUL；终端 ID 与目录仍按各自参数规则校验。按保存标签恢复为活动终端时自动挂载，不等待再次点击标签。
- 终端右键菜单复用 Radix 的复制/粘贴：无选区时复制禁用，未连接/已退出或宿主不支持时粘贴禁用；关闭后回终端焦点，切去其他输入或隐藏时不抢回。macOS 保留 xterm 默认右键选词行为。复制读取真实终端选区，失败反馈。
- 菜单粘贴通过 `terminal.paste`，主进程先验证现有 grant、session 和 PTY owner，再读取一次系统文本、归一换行并按当前 xterm bracketed-paste 模式写入一个指定 PTY。返回 void，页面不接收剪贴板内容，不新增 iframe clipboard-read；空内容不写，超限/读取失败保留错误。Ctrl/Cmd+V 仍走 xterm 单 native paste 事件。
- 终端不可用时显示宿主能力状态和恢复提示，不伪造“正在连接”。
- Plain HTTP(S) 与 OSC 8 HTTP(S) 链接悬停有下划线/手型，点击打开当前主任务的浏览器资源；支持逻辑换行、宽/组合字符，尾标点不进入网址。非 HTTP(S)、隐藏/已关闭或旧 owner 不发导航，不直接开系统窗口。

### 8.6 浏览器

- 工具栏 48px，ghost 图标按钮和地址栏 28px，提供后退、前进、刷新/加载旋转、回车提交地址与 Radix 提示；请求、导航事件及真实标题绑定来源任务与浏览器资源。更多菜单提供默认浏览器打开及指定 guest 开发者工具，经任务/资源授权桥执行。
- 本机/私网/`.local`/`.test`/非443显式端口默认 HTTP，公网默认 HTTPS；显式 HTTP(S) 保留，空白、凭据与不允许协议拒绝。主页面失败保留到下一次加载，子框架失败与取消导航不覆盖页面；错误画布隐藏 guest，提供原失败地址重试，证书失败提供检查说明。
- 空浏览器入口和普通终端网址每次新建独立标签/guest，包括重复相同网址；当前标签内提交地址、后退/前进/刷新使用自身 guest 和历史。观察到的 URL/重定向只更新来源标签，不反向重载，迟到请求 ACK 不覆盖真实地址。
- 切换标签、任务或隐藏工作区保活 guest，只有当前任务的选中浏览器可见；搜索/菜单等浮层打开时隐藏，关闭后恢复同一资源。背景事件不写入当前其他任务。
- 关闭标签精确释放 guest 和监听，最近关闭保留 URL/标题，恢复时新建资源身份与 guest；历史不伪装成恢复。关闭其他/全部只影响当前任务。宿主断连清理所有资源及在途授权，关闭/替代后的迟到导航不得创建页面。
- favicon 来自实际 guest 事件，仅接受 HTTP(S) 无凭据地址；失败回退地球图标，按资源/URL 缓存与偏好保存，关闭恢复保留图标。
- 自由尺寸提供 393×852 默认 viewport、适应及 50–200% 预览，宽 320–3840、高 320–2160；Enter/失焦提交，非法草稿保留并提示，Escape 恢复，边角可拖拽/键盘调整。尺寸与比例由授权宿主应用到真实 guest，模式切换保留页面状态，画布超出部分裁剪；显示偏好合并保存、导航等待、失败可重试。
- 工具栏选择网页元素，网页中显示蓝色选区及尺寸/颜色/字体浮层；点击拦截网页动作并采集限定字段快照。Esc、再次点击、导航、隐藏、关闭或换任务取消，迟到结果按任务/资源/run 丢弃。React 不获得任意脚本执行入口。
- 引用在 Composer 正文上方聚合为 32px 的“N 个网页元素”胶囊，320px / 12px 圆角 HoverCard 展示元素名称、标签/role、页面来源；长标题截断，支持单项/全部删除。ArrowDown/点击可展开，Esc 收起并返回触发按钮；删除最后引用返回编辑器。悬浮详情隐藏原生 guest，收起恢复。正文、文件和会话引用保留，最多 8 个/64000 字符。
- 已发送消息使用右对齐只读胶囊；完整快照保存在原用户消息中并发送给模型一次，成功提交只清当前草稿。旧纯文本草稿及 trim 后纯网页消息可恢复；非法快照保持可见原文。
- 旧 `browser` 偏好和无资源参数调用兼容。同一窗口跨任务累计 32 个逻辑浏览器标签（包括空白）；超过时关闭最近活动最早的未保护后台标签，先保存删除/最近关闭再释放 guest。当前可见、加载、媒体、下载/捕获及 viewport/picker 操作受保护，全部受保护时暂时超限，结束后再评估；上限内不轮询。保存失败保留页面，选择/活动/保护变化或复核失败恢复存储；并发工作区修改保留，删除任务移除工作区记录。概览支持有界搜索/类型提示/就地关闭及最近关闭恢复，具体交互见8.1。

### 8.7 工作区状态保存

- workspace preference 成功读取后才 ready，失败显示错误并可重试，禁止用初始空状态覆盖持久化值。
- 晚到 hydration 合并未触碰会话；同会话本地修改和主动关闭全部标签的 clearing 优先保留。按 key 顺序写入最新 snapshot，保存期间的新修改继续合并并写入。
- 受控路由离开前等待读取完成和最新保存成功；保存失败显示错误、阻止离开，retry 成功后再导航。快速 unmount 在控制器仍有效时尝试合并并保存；force reload 或进程终止不保证异步保存完成。
- 此契约针对已复现的读/写/离开风险；此前缺少 session/target/timeOrigin 的九标签变零观察仍未归因。

### 8.8 工作区监听与自动刷新

- `files.watch({ sessionId, paths }) -> { watchId }`、`files.unwatch({ sessionId, watchId })` 与文件变化事件使用当前第一方授权；订阅绑定 renderer owner/grant/session/canonical root/`dev:ino`，客户端不能监听任意路径。每订阅最多 256 个目录（含 root），每 owner 最多 8 个订阅。
- 只监听 root、当前可见展开目录与已打开预览的父目录；使用非递归 `fs.watch`，不轮询。宿主 150ms 合批，React 共享树/预览订阅并以 300ms 合批；这些预算是实现策略，不是端到端硬延迟承诺。
- 每批复核子目录 canonical/inode；替换后重绑，消失时监听存活祖先，恢复后重绑。alias 改指另一个已监听目录也发全失效；授权 root 身份变化则停止旧监听并提示重新打开，不跟随旧权限跨目录。
- 自动刷新保留展开/选中及当前标签，搜索绕过缓存重扫；非活动预览延迟到激活再读。文件删除保留 tab、显示可恢复错误，恢复后重新读取；不把文件监听变化写成聊天运行事件。
- 文件树首次读取、reveal、手动/监听刷新共用每个数据源最多两项的实际在途目录读取队列。旧 epoch 请求直到完成才释放预算，取消排队项需 settle；这不是所有文件预览和宿主文件系统操作的全局并发上限。
- 监听启动或运行失败、超限有具体错误与 retry/手动刷新入口；切会话/root、无可见文件工作区、grant 撤销、主 renderer 非同文档主框架导航/崩溃/销毁均释放对应监听，宿主同时回收 PTY。

### 8.9 外部编辑器与打开方式

- Header 使用 28px 主打开按钮与 20px 下拉按钮组成稳定分体控件，Radix 菜单宽 160px；主/子菜单的最大高度取 Radix 提供的可用高度，超出内容在菜单内纵向滚动，短桌面窗口中末项仍可达。当前图标有 tooltip，打开中禁重复触发。目录入口排除仅支持文件的应用；文件树“打开方式”子菜单与预览工具栏支持打开当前文件。
- `editors.list({ refresh? })` 只返回已安装的固定 Mira editor ID、名称、可用图标和文件限制；检测使用 30 秒缓存，重探测强制刷新。同一探测最多 4 worker；失败先等待在途任务排空再释放 pending，不能让 retry 叠加超过预算。图标为有界 32px PNG，图标读取失败不阻止已安装应用打开。
- `files.open-editor({ sessionId, path, editorId })` 在宿主重新验证安装状态、会话所属 root 和目标类型；仅打开授权目录内文件/目录，拒绝越界及不支持目录的应用。使用参数数组与 `shell:false`；Windows detached GUI 启动成功不等待应用退出，不用超时杀用户编辑器。Finder/Explorer 的文件打开为系统揭示。
- 检测与偏好读取错误分别保留；检测成功不能清掉偏好读取错误。“重新检测”仅在偏好读取失败时同时重试 hydration，正常重探测不重复读取偏好。失败 launch 不阻断尚未完成的初始/重试 hydration；成功显式选择构成屏障，晚到偏好读取不能覆盖它。
- 显式选择后仅成功 launch 才保存最新选择；普通重复打开不改偏好，卸载/controller 变化后的迟到 launch 不保存。偏好写入失败通过严格保存路径反馈，不能静默吞错。安装、偏好读取、打开及保存失败均提供实际错误和重试/改选入口。
- 外部编辑保存由第 8.8 节刷新预览，不引入内置 dirty 状态、任意文件编辑器或 `⌘S` 写回。真正打开和外部保存需原生操作验收，菜单截图/静态测试不能替代。

### 8.10 位图与 SVG 只读预览

- 位图通过 `files.read-image({ sessionId, path })` 读取当前会话/项目授权 root 内的相对路径；支持 APNG、AVIF、BMP、GIF、ICO、JPEG/JPG、PNG、WebP，实际解码能力仍由桌面 Chromium 判断。宿主不接受任意绝对路径或 URL，拒绝越界与 root 外符号链接，只返回允许 MIME 的图片数据。
- 单位图预览上限 4MiB。宿主以有界 handle 读取，读取前后复核文件 `dev:ino`、size/mtime/ctime、路径和 root 身份；增长、替换、root 变化或不可读给出实际可恢复错误，不使用无界 `readFile` 读取位图。客户端保留会话/root 身份和过期响应抑制，不能凭前端类型判断放宽宿主授权。
- 预览保持 40px 工具栏；位图使用 8px 透明棋盘和文件名 `@Nx` 显示尺寸，支持加载、解码失败提示与 retry。不提供文本内容复制或自动换行；PNG/JPEG/GIF/WebP 的预览和文件树可加入对话，其他位图格式禁用并提示转换。预览加入要求实际读取/解码成功、当前任务且 active，文件树仍由宿主校验实际内容；复制路径、刷新和外部打开保持可用。
- SVG 使用既有文本读取与 XML 源码显示，预览将源码编码为 `<img>` 数据源，不直接注入 DOM；可切预览/源码。图片解码失败只影响预览：失败预览态禁加入，读取成功的源码态仍可复制、换行和加入；读取失败则文本动作也不可用。加入是 SVG 文本附件，不是模型图片输入；继续遵守单文件 256KiB、累计 1MiB、最多 12 项，不自动发送。
- 位图/SVG 复用第 8.8 节共享监听、会话/root 身份隔离、非活动预览延期读取和删除恢复；切会话、移动项目或身份变化不得显示旧图片。刷新/重试沿用读取生命周期，不新增内置 dirty 状态或写回。
- 验收要求：安全/限额/身份与动作回归、生产 JS/CSS 和图片 helper 的无头解码/布局 fixture，以及正式 Electron 浅深色原生操作和同态 ZCode 图片比较分别记录。覆盖透明位图、`@Nx`、SVG 源码切换、decode 失败/恢复、文本动作限制和会话/root 更新；headless 不代表真实 grant/native/Vue 设置通过。最终自动检查与限定结论只引用 [图片证据页](./assets/mira-zcode-alignment-2026-10-08/IMAGE_PREVIEW_EVIDENCE.md)，同时补上轮错误态浅深复拍和复评确认；本节要求不代表验收已通过。

### 8.11 Git 文件树状态叠加

- 文件名按直接状态着色，直接状态显示 `M/A/D/R/U`；目录直接状态也可显示字母，后代状态汇总为单个 dot，`M` 优先于 `A/D/R/U`，tooltip/可访问名称保留具体状态集合。deleted 只在已有 `entries` 的已加载父目录合成缺失文件行，不造缺失祖先、不覆盖实际项、不改文件数据源快照，按父目录去重并批量合成。
- 28px Lucide 图标开关提供只看变更，使用既有选择色、tooltip、动态 aria-label 和 aria-pressed。树态保留变更文件及其已有祖先，搜索态仅直接非 ignored 状态，重算可访问同级位置；不扫描或强制展开，不改变完整树驱动的目录加载/监听。搜索使用实际文件索引，不注入 deleted 名称，这是上游真实限制。
- D 行点击/Enter/Space 只选中，不读文件或打开预览；Open/打开方式及 editor 回调禁用。保留路径复制与非位图加入对话，这是上游动作：加入只产生可移除 chip、不读取，实际发送由宿主校验真实文件，缺失时走既有草稿/chip 恢复；不把添加引用表述成文件可读。
- `files.git-ignored({ sessionId, paths })` 按当前可见路径精确判断 ignored；仅该行灰显，不给祖先目录着色或追加后代点。目录可因自身精确命中灰显，不能由某个 ignored 后代推断整目录忽略。
- `files.git-status({ sessionId }) -> { available, entries }` 与 ignored 读取从持久化会话解析授权 root，使用异步 `execFile`、NUL parser；不信任调用方路径或继承的 Git repository 环境覆盖。前后复核 root/repository/metadata 身份，IPC 返回前复核 grant/session/root，变更中的旧结果不可发布。
- 后端最多两条 Git 命令同时运行、最多 16 条等待；每条 10 秒超时、stdout/stderr 各 8MiB，进程 stdio 排空后释放槽位。React status 与 ignored 各自单在途；ignored 每批最多 512 可见路径、缓存已查路径，刷新重建缓存，version/active guard 拒绝旧响应。
- 首次进入、手动刷新和工作区变化通知触发 Git 刷新；loading 保留最后成功 available/index 与筛选，清 ignored cache 并推进 version guard，显示读取中。切换筛选不清 query/展开/selection，刷新期间 deleted 行、其菜单与已聚焦行保持；明确失败/非仓库、session/root 变化才清快照并重置筛选，普通树仍可浏览。非仓库 `available:false` 不显示 Git 错误；Git 缺失、超时、超限或失败提供脱敏错误和 retry。无 Git 写操作或 metadata watcher，外部 `git add/commit` 不保证自动刷新，可手动更新。
- 搜索 ignore 规则/配置已接入第 8.12 节；本节不表示完整 Git 文件工作区或 metadata watcher 完成，旧能力审查保留当时范围。
- 验收分别记录真实隔离 Git helper/状态解析与预算回归、grant/IPC 单测、正式生产 React + MessageChannel + 实际第一方桥/parser 的 headless，以及真实 Electron 浅深色操作/同态 ZCode 比较。watch 通知为 fixture、剪贴板为 iframe stub，不等于原生监听、grant 或 Vue 设置通过；最新证据统一见 [删除与筛选证据页](./assets/mira-zcode-alignment-2026-10-08/GIT_FILTER_EVIDENCE.md)。新独立源码/10 图逐张复核 slice-pass，文档一致性复核通过，旧 overlay ship 不覆盖本批，原生验收待完成。

### 8.12 搜索忽略规则与平台设置

- 规则作用于非空 query 的实际文件搜索。文件抽屉、Composer `@` 和 Command Center 已复用 `files.search`，因此使用同一规则。浏览树、预览、上传和 Agent 文件权限不使用 matcher，不能把 ignore 当权限或秘密隔离；Git ignored 行装饰也是独立语义。
- 使用成熟 `ignore` 7.0.5 解析器；首次非空搜索安全初始化根 `.miraignore`，设置读取缺失文件只返回模板、不落盘。模板由根 `.gitignore` seed 与上游默认段组成，落盘后不自动同步；空规则允许搜索依赖/默认排除目录，根 `.miraignore` 自身不进入候选。保留 Mira 既有 dotfile 搜索，不追加上游 `.env`/二进制/隐藏目录候选排除。
- Vue `/settings/file-search` 归平台设置，复用 SettingsPageShell/Element Plus/AppIcon；工作区选择器只提供 DB 已有项目及个人会话工作区，无任意路径输入。没有工作区显示空态，加载失败显示具体安全错误与重读入口；加载成功前禁编辑和保存。
- 同步 `.gitignore` 只替 seed、恢复默认只替 defaults，保留当前草稿的自定义/未变段，保存才落盘。分区标记缺失或重复明确报错，保留草稿，不静默重建。处理中禁重复操作；模板可未修改首次保存，已有文件仅修改后可保存；超过 256KiB UTF-8 字节禁保存。
- 重读/换工作区/受控路由离开遇未保存修改，显示“放弃修改”/“继续编辑”确认；撤销回到已加载内容。读写/同步失败保留草稿，revision 冲突要求重读，不自动覆盖；晚到/卸载请求不应用。force reload、进程强退或 OS 关闭不保证草稿保存。
- IPC 仅顶层 renderer，以 `{kind:'project'|'session', id}` 从 DB 推导根目录；固定文件名、有界 UTF-8 handle，拒 symlink/特殊文件。初始化 hard-link no-replace，保存按 root 串行、revision/授权复核、flush 后原子替换并保留 mode。所有最后 awaited 检查后同步授权紧接 link/rename，覆盖保存与首次搜索初始化；最终 syscall 的跨进程非 CAS、root 移走临时文件残留及 hard-link 不支持显式失败仍有边界。
- Vue target 使用 `shallowRef` 和普通 `{ kind, id }` 请求快照，初读、重读、transform、save 不将 `ref` 数组中的 Proxy 传入 `contextBridge`；真实 Electron 的克隆失败 P2 已复现、修复并通过回归及独立源码复核。
- 规则在进入子目录前剪枝；每查询读取规则，缓存绑定 canonical root/`dev:ino` 与规则版本/hash，编辑/删除/重建失效，旧扫描不能污染新规则缓存，warm 返回复核 root。只读/权限失败时搜索可用内存模板；危险链接/特殊文件/错误编码不能静默降级。
- 上游 3.14.3 导航实际隐藏该 section；Mira 有意提供 Vue 设置入口，不称隐藏上游页的原生逐像素对照已完成。本批检查和限定评审见第 26 节与独立证据页。
