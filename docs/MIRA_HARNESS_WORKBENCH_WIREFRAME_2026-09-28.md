## 定位与结构

Mira 外层 Shell 保持窗口控制、应用切换、全局搜索和统一设置。应用画布由 React Harness 自己组织；不在 Shell 中放 Harness 会话侧栏。

```text
Mira Shell：应用切换                                  全局搜索  设置
┌──────────────────────────────────────────────────────────────┐
│ 会话入口  当前任务 / 工作目录                 状态  工作区入口 │
│ 任务线程（默认占满画布）             │ 工作区（按需展开） │
│ 会话入口 → 覆盖式抽屉                │ 标题 / 关闭       │
│ 有进展时才出现悬浮任务摘要           │ 已打开内容标签    │
│ 用户 / Mira / 过程 / 阻塞确认        │ 活动 / 文件 / 变更 │
│ 模型 / 执行模式 / 输入 / 发送或停止  │ 终端 / 浏览器     │
└─────────────────────────────────────┴───────────────────┘
```

任务线程始终是默认主视图。新建但尚无内容的会话不自动展开工作区，也不显示空任务摘要；用户点击工作区按钮或文件变更入口时展开侧边面板。会话列表以覆盖式抽屉出现，不挤压线程。工作区宽度可调整，展示文件、变更、终端、浏览器等工作内容，不复制第二份聊天。任务有消息、活动或待确认事项时才显示悬浮摘要；审批、澄清和计划确认仍在线程中完成。

## 待确认的桌面原型

1. 空会话：仅主线程与输入区；工作区入口保持可见。点击“创建任务”时从左侧覆盖式抽屉选择个人或项目工作区。
2. 执行中：线程连续呈现用户请求、Mira 回复和阻塞确认；悬浮摘要只保留当前阶段与跳转入口，不重复完整活动列表。
3. 工作内容：右侧按需展开；顶层是工作区标题及关闭按钮，其下是已打开内容标签。加号打开文件、变更、终端或浏览器；原型可关闭已打开的标签，正式应用中切换标签应保留终端和浏览器状态，关闭标签才回收资源。独立原型不模拟真实资源生命周期。
4. 结果与恢复：文件变更在消息末端有直达入口；失败、停止和待审批都留在原会话继续处理，不另建结果页。

这份原型只锁定信息架构与交互，不代表视觉细节、所有旧 Vue 能力迁移或默认入口切换已获批准。高保真阶段应先补齐空态、执行中、审批、结果、文件/终端/浏览器六类画面，再进行正式 UI 替换。

## 开源组件使用边界

- 会话线程和输入区继续使用当前已接入的 `@assistant-ui/react`；图标继续使用已安装的 `lucide-react`，不另造一套消息运行时或图标体系。
- ZCode 的 `AnimatedSidePanePanel.tsx` 约 1,379 行，直接依赖其服务容器、文件预览、浏览器、Git 和多种工作流面板，不能作为 Mira 的独立 UI 包直接复制。借鉴其“可调整面板、动态内容标签、加号菜单、状态保留”交互，而不是导入整份工作台。
- ZCode 的标签和菜单基础来自 Radix/shadcn 组件；高保真实现可按实际交互需要引入 Radix 标签、菜单原语，但须保证终端和浏览器切换标签时保留实例。现有拖拽宽度逻辑先作为功能基线，不为了换库而重写已工作的宿主生命周期。
- ZCode 仓库采用 Apache-2.0；如后续直接复制其源码或资产，需要保留相应许可、NOTICE 和修改声明。仅参考信息架构与交互时不复制源文件。

## 原型状态

| 状态 | 主线程中的内容与动作 | 工作区重点 |
| --- | --- | --- |
| 空态 | 明确选择个人工作区或项目，再创建任务；未创建前不自动发送 | 默认关闭 |
| 执行中 | 用户任务、Mira 增量回复、活动摘要；停止当前运行 | 阶段、工具记录、目录 |
| 计划确认 | 理解、步骤、风险；确认并执行或补充要求 | 等待确认与定位入口 |
| 澄清问题 | 单选/多选和自定义回答；提交后回到同一任务 | 等待回答与定位入口 |
| 权限审批 | 操作目标与影响；拒绝或允许当前操作 | 等待审批与定位入口 |
| 成果交付 | 结果摘要、引用依据、文件变更；继续修改沿用当前会话 | 文件 diff、活动与工具记录 |
| 部分操作未完成 | 保留成功结果，明确失败操作和继续入口 | 失败工具记录 |
| 失败恢复 | 错误原因、已完成内容、重试或检查活动 | 错误与活动记录 |
| 停止后继续 | 已生成内容保持可见，继续当前任务 | 停止状态与历史活动 |
| 未配置模型 | 发送不可用，进入统一模型设置 | 默认关闭 |

## 功能归属与迁移提示

- 当前 React 正式入口已经接入会话/项目列表、选择工作区创建任务、模型、直接执行/先出计划、发送/停止、权限、计划/澄清、活动、工具、持久化 diff、会话目录打开及恢复。原型中的这些入口可对照现有实现。
- 旧 Vue 工作台还有引用文件、Skill/MCP、权限级别、Git 分支、长期记忆、会话重命名/置顶、消息编辑重跑、引用来源与用量等能力。线框只在“内容与工具”和相关上下文中给它们留位置，**不表示 React 已接入或这一批必须全部迁移**；高保真前逐项决定保留、合并或延后。
- 文件成果目前是已持久化变更的 diff 预览和打开会话工作目录，不是任意文件打开器；原型不得将“查看变更”画成任意文件预览能力。
- 原型中的文字、项目和路径均为示例，不读取用户模型或文件。设置页、Mira Shell、Novel Studio 和 Vision 不在本次设计范围内。
