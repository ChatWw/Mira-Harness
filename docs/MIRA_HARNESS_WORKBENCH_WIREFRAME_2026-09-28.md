# Mira Harness 工作台交互原型（2026-09-29 ZCode 结构重绘）

> 状态：ZCode 结构重绘原型及高保真首稿，待用户确认。已在 React pilot 中落地可交互骨架、受控文件面板、终端和浏览器面板；用户截图是设计参考，不代表最终设计已批准。

## 定位与结构

Mira 外层 Shell 保持窗口控制、应用切换、全局搜索和统一设置。应用画布由 React Harness 自己组织；不在 Shell 中放 Harness 会话侧栏。

```text
Mira Shell：应用切换                                  全局搜索  设置
┌──────────────────────────────────────────────────────────────┐
│ 会话入口  当前任务 / 工作目录                 状态  工作区入口 │
├───────────────┬──────────────────────────────┬───────────────┤
│ 会话抽屉      │ 悬浮任务摘要（可展开）         │ 工作区面板     │
│ 按需打开      │ 任务线程（始终为主阅读流）     │ 按需打开       │
│ 新任务/历史   │ 用户 / Mira / 过程 / 阻塞确认  │ 概览 / 文件    │
│ 项目归属      ├──────────────────────────────┤ 变更 / 终端    │
│               │ 内容与工具、权限、模式、模型   │ 浏览器         │
│               │ 输入、发送或停止              │               │
└───────────────┴──────────────────────────────┴───────────────┘
```

有活动任务时默认显示线程和右侧工作区；空态仍以线程为主。会话抽屉和工作区都可由应用内按钮打开/关闭，较窄的桌面窗口一次只展开一个。工作区展示任务上下文，不复制第二份聊天。悬浮摘要提供当前任务状态、运行中的活动和变更数量，并可跳转工作区。待确认节点位于线程末端；工作区只给定位入口，共用同一份状态。

## 原型状态

| 状态 | 主线程中的内容与动作 | 工作区重点 |
| --- | --- | --- |
| 空态 | 明确选择个人工作区或项目，再创建任务；未创建前不自动发送 | 默认关闭 |
| 执行中 | 用户任务、Mira 增量回复、活动摘要；停止当前运行 | 阶段、工具记录、目录 |
| 计划确认 | 理解、步骤、风险；确认并执行或补充要求 | 等待确认与定位入口 |
| 澄清问题 | 单选/多选和自定义回答；提交后回到同一任务 | 等待回答与定位入口 |
| 权限审批 | 操作目标与影响；拒绝或允许当前操作 | 等待审批与定位入口 |
| 成果交付 | 结果摘要、引用依据、文件变更；继续修改沿用当前会话 | 文件 diff、活动与工具记录 |
| 部分操作未完成 | 保留成功结果，明确失败操作和继续入口 | 失败工具记录 |
| 失败恢复 | 错误原因、已完成内容、重试或检查活动 | 错误与活动记录 |
| 停止后继续 | 已生成内容保持可见，继续当前任务 | 停止状态与历史活动 |
| 未配置模型 | 发送不可用，进入统一模型设置 | 默认关闭 |

## 功能归属与迁移提示

- 当前 React 正式入口已经接入会话/项目列表、选择工作区创建任务、模型、直接执行/先出计划、发送/停止、权限、计划/澄清、活动、工具、持久化 diff、会话目录打开及恢复。原型中的这些入口可对照现有实现。
- 旧 Vue 工作台还有引用文件、Skill/MCP、权限级别、Git 分支、长期记忆、会话重命名/置顶、消息编辑重跑、引用来源与用量等能力。线框只在“内容与工具”和相关上下文中给它们留位置，**不表示 React 已接入或这一批必须全部迁移**；高保真前逐项决定保留、合并或延后。
- 文件成果目前是已持久化变更的 diff 预览和打开会话工作目录，不是任意文件打开器；原型不得将“查看变更”画成任意文件预览能力。
- 原型中的文字、项目和路径均为示例，不读取用户模型或文件。设置页、Mira Shell、Novel Studio 和 Vision 不在本次设计范围内。
