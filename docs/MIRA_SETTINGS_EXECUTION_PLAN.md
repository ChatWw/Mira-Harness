日期：2026-10-21。适用仓库：Mira-Harness。目标平台：Electron 桌面端。

## 可直接设为目标的任务描述

以新版 React Harness 的实际执行链路为准，完成 Vue 设置中心的能力清理、导航重组和界面统一。设置侧栏采用 Harness 默认的 280px 宽度，隐藏滚动条但保留滚动；主体参考本地 ZCode 的独立内容面板、顶部留白、居中内容列和设置分区布局，沿用 Mira 浅深色语义变量。保留有效的 Vue＋Element Plus 表单、保存与错误反馈，逐页处理不一致的控件样式和动画。撤下仅旧版使用或未接入执行的设置入口，修正权限、搜索、备份和关于页的作用范围说明。完成针对性回归及 Electron 桌面验收，记录证据、失败和未验范围；不得以构建通过代替运行验收。

不扩展通知、完整数据备份、Python 环境管理等新产品功能；不迁移整个设置中心到 React；不改写 Harness 运行协议、不清除历史配置、不覆盖其他未提交工作。未达成全部验收条件时不能将目标标记完成。

## 能力取舍与完成标准

“接通”必须能追踪到设置写入、读取及新版行为消费。只有 IPC、存储字段或成功提示，不足以证明接通。以下判断是当前源码基线，执行时须复核当前 checkout。

| 内容 | 处理决定 | 完成标准 |
| --- | --- | --- |
| Git 设置整页 | 撤下入口 | 分支前缀仅发现旧 Vue 入口消费；其余 PR、强制推送、评审、提交指令等未找到执行消费。不影响新版 Git 状态及差异查看；旧地址安全回落 |
| Python 环境整页 | 撤下正式设置入口 | 检测与 pip 安装虽有实现，但未找到新版 Harness 使用同一适配器的证据；不向用户承诺安装后 Agent 一定可用；旧地址安全回落 |
| 复制当前布局配置 | 移除普通设置入口 | 不再将旧 layout store 的 JSON 称为完整工作台布局；不新建诊断体系 |
| 模型、权限、对话输入偏好 | 保留 | 设置保存后，新版任务或输入区表现按既有生效时机更新；失败不产生成功假象 |
| 指令、记忆、称呼和语气 | 保留 | 核实宿主实际注入，区分全局与项目范围；记忆关闭和删除含义明确 |
| 插件、MCP、技能 | 保留 | 全局启用、项目可用与当前任务选择的区别明确；管理入口不重复创建状态源 |
| 智能体、命令、Hooks | 保留 | 当前入口、项目范围、保存及运行消费均有证据；发现失效子项逐项撤下，不为保留旧 UI 补新功能 |
| 搜索忽略规则 | 保留 | 说明仅影响搜索，不是文件访问权限；项目选择、保存、未保存离开保护有效 |
| 回收站保留时间 | 保留并迁移 | 放到数据与配置，不改原有保留天数及清理时机语义 |
| 配置导入导出 | 保留并更名说明 | 明确包含菜单、微应用、偏好；不称完整 Harness 备份；任务、消息、模型凭据、记忆及项目文件等范围分别核对说明 |
| 恢复默认配置 | 保留并准确提示 | 列明会重置的配置及工作台偏好；明确不会恢复哪些任务数据；失败可恢复 |
| 快捷键、窗口行为、主题、用量 | 保留 | 快捷键以新版实际支持列表为准；窗口行为及统计查询有桌面验证 |
| 关于 | 更新文案 | 对齐 Harness 主体定位；不再宣称在线调用时所有数据都不离开本机 |

撤下入口不等于删除旧存储字段或迁移用户文件。旧字段先保留兼容；不得借此清理无关旧模块。

## 分步执行与文件范围

### P0：公共布局（本轮）

主要文件：`src/pages/backend/settings/components/SettingsSiderMenu.vue`、`SettingsPageShell.vue`。

- 左侧固定 280px；不使用 `overflow: hidden` 代替纵向滚动。隐藏侧栏滚动条，保留滚轮、触控板及键盘焦点滚动。
- 右侧主体与外层背景分离；普通页使用 896px 内容列、32px 横向内边距，页头与正文对齐。
- 主体独立滚动，顶部留白不随正文滚动；模型工作区由内部列表和详情承载滚动，不出现被锁死的内容。
- Windows 标题栏、macOS 红绿灯和拖拽区保留；表单、弹层、返回按钮不能落入不可点击的拖拽区。
- 桌面端保持左右布局，不新增移动布局或窄屏断点。

验证：常规长页、快捷键页、模型页、插件页、关于页；明暗主题；侧栏最后一项可达；两侧独立滚动；布局无横向溢出。

### P1：撤下无效能力与导航重组

主要文件：设置导航、`src/router/index.ts`、`src/platform/firstPartyNavigation.ts`；必要时更新现有命令入口配置及引用旧地址的 UI。

先核对引用，再撤下 Git、Python 正式入口，处理旧地址回落；按目标导航分组。不得先批量删除 backend 目录、IPC 或数据库字段。

验证：新版菜单、直接打开旧链接、返回 Harness、项目参数保留、MCP 兼容地址；保存失败与未保存离开保护不得被跳转绕过。

### P2：迁移有效设置并修正说明

主要文件：`general`、`personalization`、`backupPreferences`、`fileSearch`、`about` 页面；必要的独立权限页及导航声明。

- 权限移出常规，名称说明其全局含义，区别“当前选择”与“允许哪些档位”；不自行改成单任务权限体系。
- 运行中消息处理补充队列与引导的用户可理解说明。
- 移除旧布局复制操作，准确说明导出和默认恢复范围；特别核对偏好里包含的工作台状态及草稿。
- 更新过期产品介绍，不为文案承诺添加尚未接通的能力。

验证：每项保存后重新进入页面仍一致，重启后按原设计保留，新版任务确实读取；失败回退和成功反馈准确。破坏性操作使用隔离测试数据。

### P3：逐页控件、布局和动画统一

主要文件：相关设置页及必要的设置专用样式；全局 `src/styles/element-override.scss` 仅在确认问题跨页面共用时修改。

- 保留 Vue＋Element Plus，不重写校验、选择器、弹窗、加载与错误状态。
- 梳理字段高度、按钮、分区标题、说明文字、卡片边界，避免页面内外重复居中和重复 padding。
- 特别检查模型管理双栏、插件详情、智能体编辑器和用量页；不能只验常规页。
- 保留有意义的加载与状态反馈；去掉查明属于旧页面装饰的入场、缩放或位移动画。不得全局 `transition: none` 或禁用 loading 动画。
- Teleport 到 body 的下拉、提示、弹窗单独检查；设置容器中的变量不会自动覆盖这些浮层。
- 遵循已有 reduced-motion 行为，不改主题切换的全局动画策略。

验证：明暗主题下的默认、悬浮、键盘焦点、禁用、加载、错误、空态；弹层不被面板裁切，滚动时无明显布局跳动。

## 验收与证据

1. 静态检查：`git diff --check`、`npx vue-tsc --noEmit`；运行改动涉及的设置、导航及权限回归测试。修复实际 bug 时先补复现测试，不添加只比对 CSS 字符串的测试。
2. 构建：Vue 设置所在 Shell 的构建成功。若改动涉及首方桥或 React 行为，再运行相应类型及构建检查。
3. 运行：使用独立测试数据目录运行 Electron，避免对用户真实配置执行重置、导入、记忆删除或包安装。
4. 几何与视觉：1440×900 和 1100×760 桌面窗口、浅色和深色；侧栏实际为 280px、滚动条隐藏但最后一项可点击，内容列及宽页无裁切。
5. 行为：逐页选择、输入、保存、重新进入、失败重试；返回 Harness 保持既有任务、草稿和工作台状态；设置期间后台事件不抢走表单焦点。
6. 系统：macOS 实际运行记录；Windows 标题栏可做结构检查，但 Windows 原生运行和安装包未经实测必须单列为未验。
