# Mira Harness 文件访问

工作目录用于解析相对路径。`read`、`list_files`、`write`、`edit` 可以访问工作目录外的文件或目录，并沿用会话权限模式：默认模式需要确认外部读取和文件修改，自动批准、完全访问模式遵循现有审批策略。主会话与子智能体使用相同的文件审批流程，子智能体原有工具限制仍然生效。

默认模式的确认只授权本次调用的目标，不会永久放开整个目录。路径会解析符号链接和 Windows junction；等待确认时目标路径或链接发生变化，需要重新请求授权。默认权限的无人值守任务不能读取外部资源，需要事先调整任务权限。

外部文件修改会记录真实绝对路径和可用的文本差异，但暂不支持自动恢复。`delete_file` 仍仅将项目内文件移入 Mira 回收站。

这些检查属于内置文件工具的访问控制，不是操作系统沙箱。命令和 MCP（包括电脑控制、浏览器操作）继续使用各自既有的审批机制；它们执行的文件操作不受上述文件工具路径检查覆盖。
